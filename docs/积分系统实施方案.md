## 二、积分的生命周期

```
用户购买套餐 / 管理员手动充值
        ↓
积分余额增加，写充值流水
        ↓
用户使用 AI 功能 → 系统自动扣积分
        ↓
生成成功 → 积分扣除，写消费流水
生成失败 → 积分自动退还，写退款流水
        ↓
积分不足 → 提示"积分不足，请充值" → 跳转充值弹窗
```

**积分只进不出**：用户不能提现、不能转让。

## 四、扣费流程（含失败退款）

### 4.1 核心逻辑

```
用户请求到达
    ↓
① checkAndDeductPoints(userId, action)
   → 查定价表 → 查余额 → 扣费 → 写流水 → 返回 { success: true, logId }
    ↓
② 执行 AI 调用
    ↓
③ 成功？ → 结束，积分已扣
   失败？ → refundPoints(userId, action, logId)
           → 退还积分 → 写退款流水 → 原消费记录标记 [已退款]
```

### 4.2 在 ai.ts 中的接入方式

```typescript
import { checkAndDeductPoints, refundPoints } from './points'

class AiText {
  async generateText(options) {
    // ① 先扣费
    const { success: hasPoints, logId } = await checkAndDeductPoints(
      options.userId, 'text_generate', 'AI 文本生成'
    )
    if (!hasPoints) {
      throw new Error('积分不足，请联系管理员充值')
    }

    // ② 执行 AI，包裹 try/catch
    try {
      const model = await resolveModelName(...)
      return await generateText({ model, ... })
    } catch (err) {
      // ③ 失败退费
      await refundPoints(options.userId, 'text_generate', logId, '生成失败退还')
      throw err
    }
  }
}
```

四个类（AiText/AiImage/AiVideo/AiAudio）各加一次。

### 4.3 在 chat.ts 中的接入方式

```typescript
import { checkAndDeductPoints, refundPoints } from '@/utils/points'

router.post('/chat/stream', async (req, res) => {
  const userId = req.user?.id

  // ① 先扣费
  const { success: hasPoints, logId } = await checkAndDeductPoints(userId, 'text_generate', 'AI 助手对话')
  if (!hasPoints) {
    return res.status(402).json({ error: '积分不足，请充值' })
  }

  // ② 执行 AI，包裹 try/catch
  try {
    // ... 原有逻辑 ...
  } catch (err) {
    // ③ 失败退费
    await refundPoints(userId, 'text_generate', logId, '对话失败退还')
    throw err
  }
})
```

## 十二、注意事项

1. **积分不足提示**：当用户积分不足时，返回402状态码，前端弹窗提示并跳转充值
2. **失败退款**：AI调用失败时自动退还积分，确保用户不会白白扣费
3. **并发安全**：扣费时使用数据库事务，避免超扣
4. **流水记录**：每笔积分变动都要记录流水，方便追溯
5. **管理员权限**：积分管理相关接口需要管理员权限
