# 项目卡片与无限画布体验优化

项目总览使用石墨场记板封面、冷灰工作台、少量琥珀状态标识；项目名称、画幅、制作状态、流水线进度、编辑与打开行为保留。视觉规则限定于项目页，其他创作页沿用已有设计。

画布初始工具改为小手移动。空白区域可直接拖动；节点自身的点击、拖动、媒体与输入操作保留，Space 仍可临时切换选择操作。

普通滚轮 100 像素的缩放变化从约 10% 提高到约 28%。像素、行、页三类滚动量统一处理，极端事件限幅；触控板捏合单独调整灵敏度。缩放以鼠标所在世界坐标为中心，同一帧内多次滚动累计后提交一次，避免丢失增量或重复处理捏合。缩放范围仍为 5%–500%。

底部使用减号、倍率、加号。加减按 1.25 倍调整；点击倍率可选择常用比例、输入百分比或使用更宽的滑条精细调整。工具条维持紧凑宽度，保留重置、小地图与快捷键。

亮色控件发黑的原因是外层 AppProviders 与上游画布各自创建了主题 store。上游改为复用宿主唯一主题 store，让画布、Ant Design 配色、根节点 dark 类与宿主主题消息一起更新。修复适用于搜索框、选择器、弹窗和对话操作按钮。

## 验证

`frontend/scripts/test-canvas-navigation.mjs` 使用真实 React 事件、原画布组件、真实主题 store 与 AppProviders，检查：同帧滚轮累计、鼠标定位、捏合仅处理一次、输入区域不缩放、小手拖动、节点操作、临时选择、快捷倍率、输入边界与明暗配色。模型和生成接口均不调用。

发布检查使用独立浏览器与模拟账号/API，验证 10588 的项目卡片、手机布局、默认移动工具、倍率入口与主题切换，保存界面截图。已有工作区的其他功能改动与数据保留。
