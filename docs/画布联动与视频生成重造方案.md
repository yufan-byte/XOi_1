# 制作页画布联动 & 视频生成重造方案（大道至简版）

> 结论先行：**删掉制作页的 VueFlow「总览画布」，无限创意画布（atelier）成为全站唯一画布，并与制作页双向打通；视频工作台的三栏表单 UI 整个拆掉，按造物「镜头流 + 底部生成台」的交互重造，生成逻辑层原样复用。**

---

## 一、现状盘点（基于代码事实）

| 界面 | 现状 | 判断 |
|---|---|---|
| 制作页·总览画布（VueFlow） | `production/index.vue:170`，默认已是步骤模式，画布作为「高级视图」保留；节点可拖拽、带审核动作 | **删**。它是一张「流程图」却伪装成画布：不能自由创作、节点布局再怎么排也是流水线，和真画布心智重复 |
| 无限创意画布（atelier，`/#/canvas`） | React 节点画布：图片生成节点（垫图/参考链/裁剪/分割/放大/遮罩/全景/相机控制）+ **视频生成节点**（`/api/canvas-video` 任务制、预扣积分、失败 CAS 退还、产物落 /oss、kling/seedance 等协议、最多 7 张参考图） | **留，升格为唯一画布**。成熟、好用、后端链路已深度打通 |
| 视频工作台（三栏表单） | `workbench/generate/index.vue`（627 行）：左镜头轨 / 中参考素材+生成设置+提示词 / 右结果卡 | **重造 UI，保留逻辑**。API（`/production/workbench/generateVideo`、`generateVideoPrompt`）与状态机没问题，问题是壳 |
| 造物视频生成（参考图3） | 对话流式：历史结果卡片流 + 底部输入台（模式切换、预计消耗前置、参数一行、提示词、参考图入口） | **抄交互，不抄代码**（atelier 本就同源，风格天然一致） |

**已有的桥（不用从零建）：**
- 出：`sendToCanvas()`（`src/utils/sendToCanvas.ts`）— `/#/canvas?import=<图片JSON>&source=xoi&from=cornerScape|assets`
- 回：画布勾选保存 → `localStorage.canvas_save_result` → 跳回 `/#/<from>`；回传路由白名单 `XOI_RETURN_ROUTES = ["cornerScape", "assets"]`（`atelier/src/xoi/bridge.ts:22`）

## 二、方案 A：画布统一与联动

### A1. 删除 VueFlow 总览画布（减法）
- `production/index.vue` 移除「总览画布」入口与 canvas 分支；步骤模式成为唯一模式（步骤头部已有 剧本→导演计划→分镜表→分镜台→视频→成片 的流程条，总览职能已被它覆盖）。
- 节点组件（script/storyboard/…）在步骤模式下以 `fluid` 形式复用，**组件不删**，删的是 VueFlow 画布壳（layoutGraph、拖拽、连线）。
- 效果：全站只剩一个「画布」心智 = 无限创意画布，不再有"这个画布是干嘛的"的困惑。

### A2. 制作页 → 画布（创意出口）
在三个痛点位加「送到无限画布」按钮（复用 `sendToCanvas`，新增 `from: 'storyboard' | 'production'`）：
1. **分镜台每帧** hover 菜单 + **联审分镜抽屉** footer —— 分镜图不满意？送画布用「垫图 + 多参考图」迭代变体，画布的参考链正是解决"场景不一致"的正确工具；
2. **视频工作台**每个历史版本 —— 送画布做首尾帧接力、局部重生成；
3. **成片输出** —— 送画布做海报图/封面精修。

### A3. 画布 → 制作页（结果回流）
- `XOI_RETURN_ROUTES` 增加 `'production'`；回跳时带 `projectId`；
- 制作页监听到 `canvas_save_result` 后弹轻量选择：**「用作该镜分镜图（替换）/ 存入项目资产」**；
- 这一步把"画布探索"闭环回"流水线生产"。

### A4.（P2）视频「去画布生成」逃生舱
视频工作台每镜提供「在画布中生成」深链：带该镜分镜图 + 提示词 + 关联资产直接进画布，重度用户可在画布节点流里多方案并行，结果经 A3 回流为该镜版本。普通用户无感，不强制。

## 三、方案 B：视频生成重造（造物式「镜头流 + 底部生成台」）

**拆掉**：三栏布局、左侧大轨道列表、右侧独立结果大栏。
**新建**：单屏三层，自上而下——

```
┌─ 镜头胶片流（横向滚动）────────────────────────────┐
│ [S01 ✓采用] [S02 ⏳生成中] [S03 ·待生成] [S04 …]    │
│  分镜图缩略 + 状态点 + 采用版本徽章；点击选中居中      │
├─ 选中镜头·版本历史条（横向小卡）─────────────────────┤
│ [v1 ▶ 6s 720p kling ✓] [v2 ▶ 8s 1080p seedance] …  │
│  每卡：视频缩略/模型/积分/采用切换/重生成              │
├─ 底部生成台（sticky，造物式输入台）──────────────────┤
│ 参考素材 chips: [分镜图✓] [人物·林昭] [场景·皇宫] +   │
│ 提示词输入 ————————————— [AI润色] [提示词大师]      │
│ 模型▾(logo) 时长▾ 分辨率▾ 比例▾ 音频○   预计~xx积分  │
│                                     [ 生成视频 ]    │
└──────────────────────────────────────────────────┘
```

要点：
1. **一屏一镜**：选中即聚焦，参考图自动带出该镜分镜图 + 关联人物/场景资产（现在要用户自己想"该锁什么"），chips 可增删；
2. **参数收一行**：模型（带品牌 logo，复用 one-stop 的 provider-logos）、时长、分辨率、比例、音频 —— 替代现在的 modeMenu 大表单；
3. **计费前置**：生成台右侧实时显示预计消耗，替代"生成完才知道扣了多少"；
4. **版本历史可视化**：替代右侧 videoCard 大栏，多版本对比采用一目了然；
5. **复用不动**：trackList 状态机、`generateVideo` / `generateVideoPrompt` API、promptEditor、imageSelect（收进 chips）、生成中轮询逻辑。

## 四、实施分期

| 期 | 内容 | 改动面 |
|---|---|---|
| **P0** | 删总览画布入口；分镜帧/联审抽屉「送画布」；回传白名单 + 制作页回流弹窗 | 纯前端（+atelier bridge 一行） |
| **P1** | 视频工作台 UI 重造（逻辑保留） | `workbench/generate/` 重写壳 |
| **P2** | 「在画布中生成」per-shot 逃生舱 + 视频版本回流 | 前端 + 少量后端参数 |

P0/P1 均不动后端计费与任务链路（已验证闭环：预扣、CAS 退还、/oss 落盘）。
