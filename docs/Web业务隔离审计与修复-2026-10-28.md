# Web 业务隔离审计与修复（2026-10-28）

本轮检查覆盖 3D 白模预演、无限画布、智能创作对话、灵感广场交接、短剧工坊的资产与分镜、独立剪辑、爆款复刻、云草稿与实时会话，并回归一站式创作已有隔离测试。没有调用真实生成模型。

## 3D 新用户为什么会有项目

宿主的 `getInitialProjects()` 在没有本机记录时直接生成“1号场景”；删除入口又禁止删除最后一个场景。这不是其他账号的云端项目，但不符合 Web 产品的新用户空状态。

现在首次访问只读取当前账号目录，返回空数组时显示“还没有场景”。只有用户点击“新建场景”才创建账号所属的独立编号；允许删除最后一个场景，删除后返回空列表，不打开无编号 iframe。云端读取失败时明确说明只显示本机记录，不把失败当作云端没有项目。

原生编辑器另有两处适配缺失：仍要求已迁移掉的 `localStorage.token`，并会自动把全局 `stageframe-project` 导入新场景。现改用 HttpOnly Cookie 认证及会话信号校验，不再导入无归属公共工程；新建场景没有演示人物和布景，默认选中相机。已有明确归属的真实场景保持保留，不批量清空老用户数据。

## 本轮修复

| 模块 | 修复 |
| --- | --- |
| 3D 宿主 | 空列表、最后一个场景删除、身份与异步请求校验、迟到重命名/删除防护、失效页面消息过滤，以及云端删除状态的目录核对 |
| 3D 原生同步 | Cookie 登录适配；读取响应体后及写本机数据前再次校验原会话；新版登录不能接收旧场景迟到写入；无项目编号的共享草稿入口被拒绝 |
| 云文档接口 | 禁止通过通用 `/workspace/documents/director/...` 绕过 3D 专用接口的归属、工程格式与删除墓碑校验 |
| 无限画布 / 灵感广场 / 导演台交接 | 提示词、附件、整图、返回图片改用当前标签页的 `sessionStorage`；按完整登录会话与用途分区，10 分钟过期，消费一次即清除；不会认领旧全局交接数据 |
| 智能创作对话 | 对话持久化固定到页面原会话，阻止延时保存把旧对话写进新账号的历史桶；技能加载与保存也补会话检查 |
| HTTP 与模型预算 | 主站 Axios、画布请求、上传和预算授权附带预期账号，结合服务端已认证身份检查；换号后的返回结果被丢弃；自动确认额度从真实会话 UID 取存储分区 |
| 实时聊天 | 握手附带预期账号，服务端与 Cookie/JWT 认证结果对照；项目与剧集归属校验继续保留 |
| 项目 / 分集批量操作 | 同一次资源操作不能混入另一个项目，即使两个项目属于同一账号；查询参数中的剧集范围也参加关联校验 |
| 画布结果回存资产 | 独立核对目标账号、项目、资产和源图片；拒绝其他账号文件、其他项目路径和非法路径；将结果归档到目标项目，再事务写入；并发图片变更返回冲突，原图不被覆盖 |
| 资产回存协议 | 修正 PostgreSQL 插入后图片 ID 的取得方式，统一返回 `data.imageId / data.filePath`；前端仅在服务端确认后更新对应资产，失败不再显示保存成功 |
| 旧图编辑工作流 | 相对路径参考图直接走带归属和符号链接检查的 OSS 读取，避免 Node 对 `/oss/...` 发无凭据或无效相对 HTTP 请求；拒绝错误项目参考图 |
| 云草稿目录 | 按分页读取完整目录，避免换设备后只看到前 50 个草稿 |
| 剪辑与复刻 | 原页面的异步保存和离线回退加入会话校验，避免换号后的旧回调继续执行 |
| 画布工程检查 | 修正宿主 / 上游两套 `@/` 根路径在 TypeScript 检查中的混用；按 Vite 的实际解析规则检查全部依赖，保留严格类型检查；同时补齐客户端 dynamic 适配类型及音频裁剪滑块参数检查 |

同账号的素材库允许明确复用；项目任务、文档、场景和返回目标需要独立定位。公共灵感作品与视觉预设仍为公共展示内容，不能据此访问别人的私有项目。

## 验证结果

- 110 项离线 / 模拟回归通过，包括新用户空列表、主动新建、删除最后一个场景、迟到重命名、原生 Cookie 登录、拒绝共享/他人场景编号、通用草稿绕过、跨项目资源混用、分页、图片回存与并发保护，以及一站式创作回归。
- 独立 Chrome 临时用户目录测试通过：真实 `localStorage` 中场景可同步到模拟云端；切换账号后旧写入抛错，原场景内容保持原样。模拟请求仅 GET / PUT 场景，没有模型请求。
- 后端 `npm run lint`、主站 Vue 类型检查、画布宿主及上游类型检查通过。
- 主站、画布和原生 3D 构建通过；最终主站构建也检查了当前分镜历史入口的完整实现。
- 本轮新增测试文件：`backend/src/utils/webBusinessIsolation.test.ts`、`frontend/scripts/test-web-isolation-browser.mjs`。

## 本地运行状态与边界

主站、白模预演和画布静态产物已同步到 `backend/data/web`，采用资源先写、入口最后切换，保留旧哈希资源，未覆盖运营公告、控制台和一站式的独立发布目录。刷新页面即可加载新版前端。

后端进程没有重启，因此本轮新增的服务端接口校验需要重载后端后完整生效。没有进行真实模型生成、扣费、生产部署或真实账号之间的在线业务操作，不能据此承诺所有上游模型线路都正常。
