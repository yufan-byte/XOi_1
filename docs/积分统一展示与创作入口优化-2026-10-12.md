# 积分统一展示与创作入口优化

## 统一单位

前端公共换算位于 `frontend/src/utils/points.ts`，Vue 主站、React 画布与 React 账户控制台复用同一实现。

- 人民币报价 × 10 = 积分；1 元 = 10 积分。
- NewAPI quota 先按 500,000 quota = 1 元还原，再换成积分。
- 已经以积分返回的余额或实际扣费仅格式化，不再次乘十。
- 报价优先使用明确的数值 `yuan`；不信任旧 `points` 或旧 `displayPrice` 字符串。缺失价格显示暂无报价，不能冒充免费。
- 账户汇总与 CSV 保留退款的负值；模型报价拒绝负值。
- 不修改账户余额、历史账单、上游价格、加价比例或实际扣费规则。

| 人民币金额 | 积分展示 |
| --- | --- |
| ¥0.006 | 0.06 积分 |
| ¥0.1854 | 1.854 积分 |
| ¥0.39/秒 | 3.9 积分/秒 |
| ¥0.75/秒 | 7.5 积分/秒 |
| ¥1.09/秒 | 10.9 积分/秒 |

注意：小额文本预估出现 0.06 积分并不等于没有换算，¥0.006 × 10 正是 0.06 积分。百万 Token 的单价也不是整次生成费用。

## 覆盖入口

- Vue 公共模型选择器、费用提示，以及复用它们的智能创作、剧本和工作区页面。
- React 画布模型目录、按秒价格卡片、当前参数预估、参考视频倍率明细。
- 账户控制台的余额、充值、消费明细、密钥消费、CSV 和模型价格查询。
- 复刻工作流的分镜报价合计。
- 财务后台中明确标注“元”的结算金额仍显示人民币，不改成积分。

## 创作入口

参考本地造物前端的分类提示词交互，提供五类、每类三个简短提示：品牌设计、影视创意、电商广告、游戏创意、网页设计。按 10 月 13 日反馈移除独立示例卡片，提示只在空输入框内以小字号文字显示。

- 切换分类只切换示例，不覆盖用户正在编辑的内容。
- 点击示例填入可修改的完整提示词；不会直接发送模型请求。
- Tab 补全使用当前分类示例；分类支持方向键、Home、End。
- 游戏和网页入口只描述设计与创意，不暗示已支持完整游戏运行或网站发布。
- 默认仅显示本次文本预估，展开计费说明才展示换算公式与图片、视频参考费用。
- 模型名称不再被重复的白色输入框和费用卡片包围；小屏工具条换行。素材、Skill、模型、图片和视频设置仍直接可见，不折叠隐藏。
- 输入框内不再出现大示例卡片；填写后小提示隐藏。工具按钮去掉大块背景，小人保留在分类栏右上边沿。
