# 任务预算与自动停止

已实现的是后端调用准入硬限制，不是“生成后弹一个超额提醒”。本地与生产都要有服务端预算授权，不能仅提交前端自造 UUID。

## 用户流程

1. 原费用确认框增加一项“本轮预算上限”，积分与人民币同时显示，仍为 1 元 = 10 积分。
2. 默认预算按报价与数量建议，最少建议 10 积分，最多不超过余额或 1000 积分；用户可调低。预算不是预扣款。
3. 每次确认对应一个后端任务。Agent 与后台批量的所有子调用沿用同一预算；前端工作流的多个独立请求仍分别确认，不会自动给自己追加预算。
4. 预算不足、达到次数上限、到期、用户停止、网关失败或价格规则变化，都阻止后续调用。继续需重新确认，不自动重试，不自动加预算。
5. 费用通知可点“停止后续调用”。已被上游接受的任务可能仍会完成或产生费用，不能把停止当作撤单或退款。

## 服务端限制

- 每轮最多 20 次真实模型 POST；免费模型也计入次数。
- 每次文本调用最多 4096 输出 Token，仅一条输出；图片数量每次最多 8 张，视频须明确 1–60 秒，语音输入最多 10000 字。
- 授权 30 分钟有效；单条 HTTP 模型请求最多 5 分钟等待。到期阻止新调用，不承诺撤销上游已经受理的任务。
- 每轮总预算不得超过当前余额或 1000 积分；在实际请求前按保守费用上界预留额度。
- PostgreSQL 行锁与原子条件 UPDATE 防止并发透支预留预算。预算与停止状态在服务器持久化，刷新页面或重启不会把已用预算清零。
- 每个预算只允许领取一次，校验账号、操作路径、有效期；请求重放不能重复领取。
- 已停止／达到次数上限的任务在读取模板、准备大素材之前先检查，不继续重复解析价格与准备媒体。带预算的任务不允许绕到其他供应商凭据。
- 生成请求用本用户的独立、有限额、会过期的 NewAPI 任务令牌。原用户目录令牌只用于读取模型目录／任务状态，不作为生成请求的无限额后备。
- 令牌不下发浏览器；预算表不保存提示词、参考素材或令牌明文。
- 报价读取真实选项；default／VIP 等内置分组未单独存储时，只读取得网关实际分组倍率，不猜零价或默认倍率。价格配置变化后既有预算停止，要求重新确认。

## 保守预留与兼容边界

- 文本按请求 UTF-8 字节、额外开销及被限制的输出长度预留，并考虑缓存变量与高价档位；不是页面的平均 Token 估算。
- 表达式使用区间求上界，不能只计算便宜分支。视频包含较高价档位和参考视频 ×1.5 的可能成本，所以预算可能提前耗尽。
- 预留不写 `users.quota`，不另建扣款账本。真实扣分仍是 NewAPI 的 `users.quota` / `logs`。
- 为避免延迟账单或异常请求使预算释放后重复花费，本轮不会自动释放预留。实际费用可能小于预留；并非多扣积分，也不是需要退还的预扣款。
- `upstream_cost` 等未知上游成本、尚未验证的多模态 Token 输入、按未知输出 Token／音频时长计费的媒体模型、远程历史／文件、内置收费工具、流式 multipart 模型接口暂时阻止调用，明确提示原因。上传素材、本地处理、普通状态查询不受此限制。
- 预算令牌实际已用额度异常超过授权，阻止后续请求并要求核对账单，不伪造退款。

## 本地 Agnes 测试价修正

只读检查发现 Agnes 上游免费，但本地 NewAPI 对未单独定价的型号使用了默认倍率 37.5。用户随后明确批准仅把本地 11 个 Agnes 测试型号设为按次零价。

通过管理 API 更新 `ModelPrice`，旧值备份到 `xoi_local_pricing_repairs`；造物型号价格、分组加价率和渠道模型列表不变。不修改用户余额或历史账单，不在生产启用 Agnes。

## 验证与不能承诺的部分

- 51 项计费、预算、价格、权限回归通过。
- 40 个真实并发 PostgreSQL 夹具请求，仅放行预算足够的 3 个；零价夹具也在 4 次设定上限停止。隔离表已清理，没有真实余额变化。
- 有限额任务令牌、有效期、预算重复领取、跨账号／跨操作请求在事务内临时夹具验证通过；未创建真实用户生成令牌，未调用模型。
- 隔离浏览器验证取消不提交、预算超过余额禁止确认、自定义预算送服务端、确认后才提交、失败费用待核对、停止按钮。
- 主站、画布、后端构建与主站／后端类型检查通过，已更新 10588。实际预算授权、停止、超额预算拒绝及四类模型预览接口检查通过；浏览器主站与画布的模拟确认流程均通过。
- 最终只读核验：11 个 Agnes 型号的网关报价均为按次零价；与备份相比仅这些型号的 ModelPrice 改变，其余型号单价保持不变。未调用任何真实生成接口。
- 已补齐一体化 Docker 构建对 `shared/` 的复制，避免干净服务器缺少共享计费／导演规则。完整 Docker 镜像构建未在本轮执行，不能将本地三个构建通过等同于镜像构建通过。
- 最终重启时上游目录有新别名变化，按原批准规则又隔离了 `seedance2.5-vd-480p` / `seedance2.5-vd-720p`。22:18（北京时间）重新同步成功，最终目录为 183 个型号，明确不兼容型号共 10 个；同步没有生成模型内容。

仍然没有进行真实收费请求验收。保守费用边界依赖模型遵守输出参数、网关价格与用量契约，不能仅凭这些模拟测试承诺“所有上游的最终账单绝对不超过 N 积分”。NewAPI 的最终用量结算仍有预消费与后结算机制，有限额令牌本身不是单次任务账单封顶的证明：[本地镜像对应的官方配额实现](https://github.com/QuantumNous/new-api/blob/2035a82aeb5414253a728bd937d4b8f97aa99b9b/service/quota.go)。

生产全部走造物、真实小额扣费／失败退款验收仍是正式交付前置项。未知成本接口不能为了“可点”而放开绕过预算。
