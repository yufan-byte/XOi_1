## 本轮修复

| 问题 | 处理 |
| --- | --- |
| 已完成的「剧本」点击没反应 | 查看阶段与后台制作游标分离；导航只更新本页状态，不写项目。任务中可回看，编辑仍受锁保护。不可达阶段明确提示前置条件。 |
| 进入「方向」「大纲」自动开始消费 | 移除挂载即生成的 effect；普通阶段切换只查看，明确点击生成或后台连续制作才提交。 |
| 补图点击立即生成、不知道结果在哪 | 新增「补图 / 换图」管理窗口，显示当前主图、候选图、上传与显式 AI 生成入口。打开窗口不报价、不提交模型。 |
| 旧主图替换后丢失 | 候选设为主图时去重保留旧主图，已有视频标记需核对，不删除原视频。 |
| 编辑画面失焦即保存、正文太小 | 改为独立描述编辑页签，明确保存/取消；保存描述不自动生图。未保存的描述不能直接用于 AI 补图。 |
| 补图在素材库不可见 | 只读汇总项目候选关键帧，区分主图和候选；「管理关键帧」可定位到该项目分镜阶段。 |
| 视频缺关键帧只有禁用按钮 | 显示缺失数量及「去分镜补图」入口，解释上传和 AI 补图的费用区别。 |
| 原生浏览器确认窗 | 重生成、移入回收、结束待核对改为站内确认；取消或关闭不提交任务。不是重新加入每次计费预算弹窗。 |
| 项目设置模型名称被裁切 | 移除固定 h-10，按内容显示模型名称和基础单价；设置按故事、规格、模型、镜头、声音分组，减少重复标签。制作中仅查看。 |
| 移动端顶部按钮横向溢出 | 允许项目工具栏换行；390px 工作台及关键帧弹窗无横向溢出。 |
| 单镜补写画面却设计整批 | 前端携带 target，后端报价与执行均验证目标存在；只向文字模型发送该镜头，不再从第一批镜头中误取结果。target 和 index 不可混用。 |
| 场景一致性参考漏传 | 分镜生图在能力限制内优先保留一张人物与匹配场景图，其后补人物/风格图；文字模型与仅文生图模型仍收到人物、场景描述。 |
| 自建风格只有名字进入模型 | 后端按当前账号查询未删除的自建风格描述，加入文本、图片和视频制作上下文，不跨账号解析同名风格。 |
| 固定镜头时长未参与剧本镜头数估算 | 按本集总时长与每镜固定时长估算，缺少时长时使用项目镜头数；单次输出仍有合理结构上限。 |
| 刷新后后台最后一步完成、页面未同步 | 在解除编辑锁前读取终态文档；不依赖本标签页是否持有提交 Promise。 |
| 打开旧项目先写默认值、随后撞上任务锁 | 初始写保护默认开启，先读取服务器任务状态，再允许补默认模型/音色。执行中或待核对时不自动保存默认配置。 |
| 小说批量失败后仍提交下一集 | 只补缺失正文；全部重写需替换确认。某一集失败/取消即停止后续集，已完成正文保留。停止操作使用上方持久任务入口，去掉误导的局部停止按钮。 |
| 「生成全部」看起来无效 | 明确为「补齐缺失定妆图」「补齐缺失关键帧」「生成待完成镜头」，全部就绪时禁用，不默默重新收费生成已有结果。 |
| 日志页没有服务器制作记录 | 服务端成功提交结果时记录最近操作；详细历史仍保留在任务及生成历史表，不清空作品。 |

## 两种模式的实际能力

- 精品剧：输入 → 意图 → 方向 → 大纲 → 小说 → 剧本 → 资产 → 分镜 → 视频/成片。
- 批量剧：系列设定 → 剧本 → 资产 → 分镜 → 视频/成片。不会伪装经过已跳过的策划阶段。
- 两条路径继续复用账号隔离的云端文档、版本校验、持久任务、模型网关、用量回执、媒体归档与 MP4 合成。
- 已有尾帧续接只对声明支持首帧的模型开放，不把不支持首帧的推荐渠道伪装成支持串行续接。
- 模型选择、编辑、候选切换与预览不调用模型；实际生成按用量结算，今日消费提醒不阻断正常任务。
