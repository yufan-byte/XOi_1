## 复核后保留的隔离设计

- 云文档主键为 `user_id + collection + document_id`；账号来自认证，客户端不能用请求体指定用户归属。读取、保存、删除均带完整归属条件。
- 项目保存使用版本比较，删除保留墓碑，防止另一窗口的旧内容复活或覆盖项目。
- 后台任务、停止、用量回执和原视频找回均先核对任务所属账号；项目后台运行状态、历史版本和恢复操作按账号及项目过滤。
- 本机媒体 HTTP 读取仍有鉴权、路径规范化和符号链接检查。保留已有 `private, no-cache` 性能策略，并实测本人条件请求可返回 304、换号或匿名条件请求返回 403。
- 同账号素材库和风格库允许用户明确复用。项目文档、任务、历史及剪辑文件独立；账号级素材复用不应被误改成项目之间互相复制状态或互删文件。

## 数据兼容与功能边界

旧 `mc-clip` 数据库没有可靠的账号、项目归属，不自动认领到当前账号；文件保留，旧项目可能需要重新上传本机素材。无传输编号的历史扫码文件不再自动取回到新窗口。旧版扫码页面需要重新扫码。

服务器保存剪辑方案，本机剪辑源文件仍留在当前浏览器，换设备不会自动带过去。上游模型的可用性、原生遮罩能力和真实生成成功率，不能由本次静态修复保证。前次功能对照见《一站式创作源码对照与修复-2026-10-27.md》。
