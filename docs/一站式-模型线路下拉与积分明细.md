# 一站式工作区：模型线路下拉重做 + 积分明细入口

> 起因：用户截图圈出右上角那块「模型线路」下拉，说"显示的很杂乱，造物很干净"；
> 同时要求"点头像或哪里能看到积分明细，显示运行了扣了多少积分"。

---

## 1. 杂乱的那块是什么

**`SeriesPicker`**（`frontend/console/src/one-stop/studio/media-page.tsx`）——
顶条右侧那个「即梦 2.0 · 专线 ▾」的模型切换下拉。

原来的实现有两个结构性问题：

| 问题 | 后果 |
|---|---|
| 把**整个目录的所有系列**都列出来（`sections` 按 series 分组遍历全部 models） | 几十行、面板又窄又长，滚动条老长 |
| 每行塞「名称 + 重点推荐 + **完整价格串** + **两行描述**」 | 一行三四段信息互相挤，名字被截成 `即梦 Fas...`，价格换行溢出到面板外 |

造物那边同一个下拉只显示**当前系列**的档位，一行一个：左边名字、右边价格、选中打勾。

## 2. 改法

```tsx
// 只列当前模型所在系列（跨系列换模型走左侧模型库，那里本来就是全量）
const siblings = models.filter(m => (m.series||"") === (current.series||""));

// 主价只取第一段，并去掉人民币括号：480p 5.833 积分/秒（¥0.5833）· 720p 7.5 …  →  480p 5.833 积分/秒
const mainPrice = m => (m.price||"按用量").split(" · ")[0].replace(/（[¥￥][^）]*）/g, "");
```

行结构：`○ 名称 [推荐] …………… 价格`，描述不进列表（侧栏模型卡里已有），
完整分档价放 `title` 悬浮；面板 370px 宽、`max-h: min(70vh,520px)`、头部固定「系列名 + N 个档位」。

## 3. 积分明细

**已有**：`components/shell/dialogs/usage-dialog.tsx`（造物 UsageDialog 移植），
数据来自 new-api `/api/log/self` + `/api/log/self/stat`，内容包含：
余额卡（累计获得 / 累计消费 / 当前可用 + 进度条）、期间消耗 / 期间记录 / 本页未扣 / 本页退款、
今日消费提醒、全部·聊天·图片·视频·音频筛选、近7/30/90天、搜索、导出 CSV、逐行展开看 tokens 与调用编号。

**缺的只是入口** —— 一站式顶栏头像菜单里没有这一项。补上：

| 位置 | 改动 |
|---|---|
| 头像下拉菜单 | 新增「积分明细」（`ReceiptText` 图标），排在「帮助中心」之前 |
| 下拉顶部的「算力余额」卡片 | 从 `<div>` 改成可点按钮，点它直接开积分明细（原来只能点外面的「充值」） |

实现：`one-stop/adapters/shell.tsx` 里 `const [usageOpen, setUsageOpen] = useState(false)`，
直接渲染 `<UsageDialog open={usageOpen} onOpenChange={setUsageOpen} />` —— 同源同 React 树，
不用再套 `/console/usage` 的 iframe。
