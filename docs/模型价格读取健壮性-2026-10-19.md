# 模型价格读取健壮性（2026-10-19）

## 本轮范围

团队功能按用户要求暂停：不发布本轮团队管理页面，不重启 12121，不改真实成员、团队名称或积分。不调用模型或支付接口。

## 修复

- `queryPricing` 原先仅调用 `AbortController.abort()`，如果调用层未响应信号，等待和缓存 pending 可能一直不结束。
- 新增真正的单次等待期限。超时或页面取消后，调用方及时收到错误；仍向传输层发送取消信号，迟到的成功/失败都有处理但不会覆盖新结果。
- 保留有界重试：目录默认单次 6 秒、一次重试和 500ms 间隔；报价默认单次 10 秒、两次重试。这不是承诺接口会更快，而是避免没有结束条件的加载。
- 本工具只用于只读目录/报价，不用于重试模型生成、支付或积分授权。真实零价仍显示零价，未知价格不会变免费。
- 校验超时和重试间隔配置，避免非法值启动请求。
- 主站网络失败提示不再要求服务器版用户安装 Windows 运行库，改为检查网络/联系平台，并提醒先核对生成和付款状态，避免重复提交。

## 验证

- 12 项价格请求与目录缓存测试通过，含不响应取消、超时有界重试、迟到响应、缓存失效、账号切换和并发共享目录。
- 5 项前端积分显示测试通过：1 元 = 10 积分、小额精度、未知与零价区分、目录从元重算、共享换算实现。
- 主站 `npm run type-check` 通过。
- 画布独立 `npm run typecheck` 未通过，报错集中于 `upstream` 的 Next 别名、服务 API 导出和配置类型，不能视为画布整包验收通过。本轮没有为消除报错而关闭严格检查或伪造接口声明。
- 6 项静态发布回归通过，新增 `main-only` 场景验证不会夹带发布暂缓的管理台/画布包，且保留旧资源和公告。
- 主站 Vite 构建长时间等待后，已核对并向本轮自己的 Vite 进程发送终止信号，不影响其他构建或后端。最终输出包含 `built in 19m 24s`，但进程退出码为 143，不按干净构建成功计入发布验收，保留生成的产物以供后续检查。
- 本轮没有执行静态发布，没有重启后端，没有发布画布或团队功能，也未进行浏览器页面验收。修复为源码待发布状态。

## 发现但尚未改动的容量问题

`backend/src/lib/model-catalog/index.ts` 的用户模型缓存超过 1000 项会整批 `clear()`，而目标是 2000 人同时在线，可能在活跃用户较多时反复冷加载；同用户的冷请求目前也没有独立 single-flight 合并。

后续应使用有界、逐项淘汰、按用户隔离的缓存并合并同用户在途读取，验证失效/更新期间旧响应不会重新写入。保持当前用户可见模型和计费分组隔离，不用全局目录替代用户鉴权列表。该优化尚未实现，不代表已经通过 2000 人容量验收。
