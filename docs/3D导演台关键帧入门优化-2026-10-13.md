# 3D 导演台关键帧入门优化

关键帧记录某一个时间点的状态。两个不同时间点记录不同的位置后，原有引擎负责计算中间状态，播放时产生位移。

人物：选中人物 → 在 0 秒摆好起点并记录 → 先移到 2 秒 → 调整人物位置或姿势并记录 → 回到开头播放。

镜头：选中场景里的主摄像机 → 在 0 秒调整位置、旋转与焦距并记录 → 先移到 2 秒 → 调整主摄像机并记录 → 回到开头播放，查看摄像机预览窗。

## 界面调整

- 原生记录按钮改为“记录镜头位置”“记录人物状态”“记录物体状态”；当前帧已有记录时显示“更新”。
- 时间线显示秒数，各轨道显示记录点数；零个或一个点时提示下一步。
- 加入可关闭的“怎么让它动？”说明，解释编辑观察视角与主摄像机、人物位移与走路动作的区别。
- 过渡方式显示“缓入缓出”“匀速”“停住后跳转”，保留原有 smooth、linear、hold 数据值。
- 说明弹窗和按钮的键盘操作不会触发后台播放快捷键。

新增 `frontend/public/monoform/xoi-keyframe-guide.js`，通过工作区辅助模块接入。沿用原生按钮事件、场景数据、记录、插值与保存，未修改编译后的渲染引擎。静态文件同步至 10588 的部署目录，未启动额外开发端口。
