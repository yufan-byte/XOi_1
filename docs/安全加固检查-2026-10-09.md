# XOi 安全加固、UI 与架构检查

日期：2026-10-09。范围：当前工作区后端、Vue 主站、React 画布与管理台、依赖锁文件及 Docker 配置。包含源码检查、隔离数据库测试、本地已有登录态验证和构建验证；未进行线上渗透、真实支付或付费 AI 生成。不能据此断言网站不存在其他漏洞。

## 本轮已修复

| 问题 | 修复后的行为 |
| --- | --- |
| 只校验请求 projectId，遗漏按 id / ids 读取或修改的资产、图片、剧本、分镜、轨道、视频、任务等 | 统一根据数据库关系查实际归属；缺失或跨用户资源返回 403，混合批量请求整体拒绝；补齐项目、剧集与父子关系检查 |
| 画布异步任务存在于全局 Map，查询/删除缺少用户隔离 | 强制记录创建者并按用户读取；运行中禁止删除；每用户最多 6 个运行任务，完成任务保留 24 小时，全局容量 2000；任务 ID 改用 UUID |
| 图片编辑流程缺少所有者字段 | 为 o_imageFlow 增加 userId；新流程强制记录用户，旧流程只能由实际关联项目授权 |
| 用户上传 SVG 或伪装媒体可形成同源脚本执行入口 | 画布上传拒绝 SVG，检查媒体文件头；历史 OSS 文档加 CSP sandbox；远程下载只允许安全媒体类型内联，其余按二进制返回 |
| 外链下载、媒体转码及爆款链接处理可以访问内网，重定向/DNS 校验不完整 | HTTP(S) URL、实际建连 DNS 答案和重定向目标校验；用户媒体不继承管理员允许私有上游的例外；补齐超时、响应字节上限和客户端断开取消 |
| 共享导演/视觉手册写接口缺少管理权限，目录参数过宽 | 限管理员；只允许单个目录名；拒绝空目录、穿越与符号链接 |
| NewAPI 停用、降权、软删除账号后，旧镜像身份可能继续有效 | HTTP / Socket / 代理身份校验读取 NewAPI 当前角色、状态与删除标记；通过 XOi 重置密码同步提升 session_version |
| AI 代理使用模糊前缀，且上传/流式调用缺少边界 | 校验路径边界，拒绝编码分隔符、路径穿越；流式上传上限 32MB、调用最长 10 分钟；断开连接取消请求，不透传上游 Cookie |
| 校验结果被丢弃，默认值、字段剥离未进入处理器 | 使用 Zod 解析后的正文/查询参数；分页、并发数、分组数增加整数与范围限制 |
| 上传、缩略图、实时连接缺少资源保护 | 上传每账号同时 1 个、全局 4 个，画布目录最多 5000 文件/1GB；缩略图限制尺寸、规格与并发；实时连接最多 8 个/账号，消息限流；断连中止 Agent |
| 依赖存在严重/高危通告，镜像可能带入本机秘密配置 | 升级图片处理/向量库等依赖；移除有漏洞的 glob 依赖与仅为 CSS 引入的 shadcn CLI；Docker 使用 Node 22、锁定 npm 安装，排除环境文件和运行数据；服务进程降为 node 用户，取消弱默认管理员密码 |

这些限制可能使原先无界的大批量请求收到 400/413/429；上传 SVG 请转成 PNG/WebP。缩略图宽高按 64 像素步长、比例按 10% 步长归并，减少任意规格产生的缓存膨胀。

## 仍需处理的安全/架构事项

1. **私有媒体访问策略**：OSS 仍是匿名可读取的文件链接。随机文件名降低猜测概率，但链接泄露后没有过期时间；建议私有桶/独立媒体域名 + 短期签名 URL，并区分发布作品与私人草稿。当前 CSP 解决的是执行风险，不能替代访问授权。
2. **持久化任务队列**：任务虽已隔离并限制容量，图片/视频兼容任务仍在进程内存中。服务重启会丢失查询状态，多副本不能共享；应将任务与幂等键持久化，引入队列/Worker、可重入状态机与失败对账。计费以 NewAPI 为权威，旧 points 兼容接口不要再作为财务依据。
3. **认证与前端边界**：JWT 仍存在 localStorage，主站/管理台/画布共用同源环境。后续迁移 HttpOnly 会话 Cookie、合理的 CSRF 防护和可落地的全站 CSP；iframe bridge 统一验证 origin、消息格式与来源，减少认证副本。
4. **数据库职责边界**：共享 NewAPI PostgreSQL 满足当前账户/分组事务需求，但业务库直接依赖其 users 表和插入适配。应明确 schema、迁移版本、最小权限数据库角色与升级兼容测试；暂不建议直接拆库，否则代理关系及账务事务会被破坏。
5. **可运维性**：补齐请求 ID、任务 ID、脱敏结构化日志、权限变更审计、队列/数据库/上游超时告警与备份恢复演练。当前限流是单进程计数，多副本部署需要共享限流与边缘入口限制。
6. **单一构建入口**：Vue 主站 + React 管理台 + React 画布以及复制的上游代码，增加重复类型和适配分叉。保留产品功能，统一 API 契约/生成类型/构建入口，明确 upstream 与本地适配层边界；把生产构建与类型检查列为 CI 门禁。
7. **权限检查可维护性**：本轮补了统一资源守卫；新增资源路由仍需登记并测试。后续将权限检查下沉到服务/仓储层，数据库查询直接带 owner/project 条件，减少依赖路径映射的长期维护风险。

Node 20 已结束支持；运行时改用仍受支持的 Node 22。[Node 官方发布周期](https://nodejs.org/en/about/previous-releases)。运行镜像升级前应在测试环境验证数据卷归属及网关连通性。

## UI 建议

本轮实际查看了项目页、画布列表，结合主站、制作与画布代码提出建议；未做全尺寸视觉验收。

- **项目页优先展示下一步**：缩小大面积装饰区；项目卡片主按钮随阶段显示“继续写剧本 / 制作分镜 / 编辑成片”，显示最近修改内容与生成进度。当前多阶段标签提供状态，但用户需要自行判断入口。
- **统一业务语言**：将 `2D_flat_design` 等技术标识显示为中文风格名；统一剧本、导演台、画布、制作页的项目/剧集名称与状态颜色。
- **把生成状态做完整**：排队、执行、可取消、失败重试、已完成清晰区分；付费生成前展示估计成本，结束后展示实际消耗，以 NewAPI 账务为准。
- **列表管理效率**：画布列表提供真实预览、搜索、筛选、最近使用、明确保存状态；删除保留恢复窗口。项目、画布、资产列表使用一致的空状态与加载反馈。
- **减少页面之间的割裂**：保留统一导航与返回项目入口；Canvas/Director 沉浸模式提供清晰退出按钮；同一数据的保存/选择控件保持一致。
- **性能与移动端**：主站大 chunk 应按 AI 助手、编辑器、制作工具拆分；缩略图与长列表按需加载。手机优先提供项目浏览、任务查看和轻量操作，复杂编辑器单独验收键盘、触控和横屏表现。

## 上线注意

这轮完成的是本地代码加固，不等于生产已生效。部署时使用新的锁文件重新安装/构建，设置高强度 `XOI_ADMIN_PASSWORD`（Compose 不再默认 admin123）；备份业务库和数据卷，再验证登录、已有画布、媒体播放和 NewAPI 计费/失败状态。需要同时处理当前工作区的类型错误及未提交改动，避免将其他正在开发的功能混入发布。
