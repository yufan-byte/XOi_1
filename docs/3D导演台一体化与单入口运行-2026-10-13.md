# 3D 导演台一体化与单入口运行

## 单入口

日常网页、API、Socket.IO 统一为 `http://localhost:10588`。已关闭本项目 50188 的 Vite 与编译子进程。主站、控制台和画布的默认 `dev` / `preview` 命令复用根目录启动器，后端开发命令也不再开启 inspector 调试端口。

`./start.sh` 使用已有网页产物运行一个后端实例，默认不运行 Vite 或 nodemon。`--build` 用于更新主站产物，`--skip-docker` 复用数据库和模型网关。重复启动只检查并复用现有服务。停止时验证进程所属目录，防止旧 PID 被复用后误关其他项目。

PostgreSQL 与模型网关是内部依赖；它们的本机端口保留。系统及其他项目的服务不属于本次清理范围。

## 3D 工作区

- 保留深灰材质与暖橙强调，提高工具文字对比度，降低独立卡片、渐变与阴影的存在感。
- 项目栏、场景工具、时间线、技能面板使用同一套工作区层次。技能面板在宽屏停靠，窄屏保留可关闭侧面板。
- 顶部可收放资源/层级/镜头所在左栏、属性栏及时间线，原 DOM 与场景状态保留。
- 时间线支持拖动高度、键盘调整和恢复；布局偏好按已验证账号隔离保存。
- 尺寸变化合并至动画帧，同步画面尺寸；初始化不依赖被遮挡 iframe 的首个动画帧。
- 场景离开时解除跨窗口观察器并清理调度，避免本次新增的布局协调层保留旧 iframe。
- 保留原 3D 引擎、动作、机位、物体、镜头、关键帧、工程保存与导出逻辑；空间坐标轴的功能性色彩和原有水印保留。

UI 协调源文件位于 `frontend/public/monoform/xoi-workspace.js`、`xoi-workspace.css`、`xoi-host.css`；从已验证身份的启动器接入。它们同步到 10588 的静态目录，不需要另开前端服务。

## 验证

JavaScript 和 Bash 语法、变更格式检查通过。默认主站开发、控制台预览、画布开发命令均复用 10588；未出现 50188、5173、5008、9229 的本项目监听。

真实 3D 页面产物在隔离 Chrome 上验证：栏位收放、尺寸变化、时间线拖动/键盘调整、键盘收放不误触播放、创建物体/镜头、层级列表、技能停靠与恢复、窄屏布局、账号布局偏好恢复、原项目管理弹窗、深色模型选择字段和占位文字均通过。无未捕获 UI 异常、AI 提交或业务接口写入。

浏览器使用测试账号和临时本地场景。API 使用隔离响应，静态产物取自实际部署目录；截图不是用户真实项目，测试创建的物体和镜头不写入用户场景。
