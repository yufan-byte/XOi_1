# 导演画布滚动与进度优化

本次调整 `production` 的画布、七个制作栏、总览工具与导演助理。原有编辑、生成、导入、剪辑、连接和助理设置入口保留。

## 使用体验

- 剧本、资产、分镜等内容区接收鼠标滚轮，滚到底部也不会误触画布缩放；空白处仍按原设置操作画布。
- 七栏采用紧凑的两排布局，内容高度受到约束，长内容在栏内浏览。首次进入显示完整制作链路，双击栏标题可放大阅读，点击总览回到全部栏。
- 每栏显示内容就绪、未开始、待生成或失败等真实状态，并提示下一项工作。原资产已经就绪时，衍生资产保持可选。
- 视频进度按本集镜头组统计，有成功状态且有结果文件才算就绪，重复尝试不会增加完成数量。空集不会显示完成；视频制作与成片归档分别显示。
- 背景、标题、边框、连线和控制条统一为柔和的导演工作区样式。控制条保留放大、缩小、百分比重置、总览和锁定节点。
- 导演总览按钮按文字宽度显示，修复固定方形按钮导致的裁切。
- 导演助理统一视觉样式，历史对话独立滚动，输入区、费用提示、设置与连接状态保持在面板内。收起后保留会话。

## 验证

- 前端 `npm run type-check`、生产构建通过；后台 `npm run lint` 通过。
- 5 个单元测试覆盖空内容、失败提示、可选图片、资产就绪、镜头组重复尝试、缺少结果文件和成片归档。
- 隔离浏览器在 1440×900、1440×720、1920×1080 检查七栏可见、无节点重叠、工具栏避让和聊天输入区布局。
- 1440×900 下总览缩放约 69%；双击标题可恢复到 100% 阅读。
- 实测内容区滚轮与滚动边界、缩放与锁定按钮、总览、助理收起及原剧本编辑入口；未触发 AI 任务或业务数据写入。
- 已将生产前端同步到 `backend/data/web`，在 10588 重新运行界面验证；后台已重新加载进度统计代码。
- 隔离布局测试主动阻断 Socket 连接；助理截图的重连提示用于检查布局，不代表实际服务连接失败。
- 使用真实项目 1790988161967、第 1 集读取处理函数验证返回：8 个资产、0 个分镜、0 个视频轨道，视频完成数为 0。浏览器布局测试使用隔离的模拟数据，覆盖实际项目当前没有的失败、生成中和完成状态。
