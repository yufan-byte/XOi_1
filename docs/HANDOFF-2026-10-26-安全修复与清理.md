## 四、环境与坑（接手必读）

- 后端唯一主实例：`http://localhost:12121`。启停用 `./start.sh` / `./stop.sh`（`ops/local-service.mjs`）。
- ⚠️ **从 WorkBuddy/CodeBuddy 终端起后端会继承沙箱文件代理**（`NODE_OPTIONS=--require node-language-shim.cjs` + `CODEBUDDY_BROKERED_FS_HOOK_ENABLED=1`），症状是"端口在听但不响应"、日志报 `connect failed: Connection refused`。`ops/local-service.mjs` 已自动净化 env，仍见症状先查日志再 `kill -9` 重启。
- `backend/src/router.ts` 由 `core.ts` 扫 routes 生成，**加删 routes 必须重启后端**（`NODE_ENV=dev` 才重生成）。
- 加表后 `npm run db:types` 更新 `types/database.d.ts`。
- 新建无 `id` 列的表必须加进 `utils/db.ts` 的 `NO_ID_TABLES`，否则 insert 补丁自动加 `returning("id")` 报错。
- 构建一律 `> log 2>&1; echo $?` 验退出码；大目录同步用 tar 管道（`cp -rf` 会被沙箱 SIGTERM）。
- `git diff --stat` 显示的 400+ 文件变动是**仓库里原本就存在的未提交改动**，不是本轮改动。
