# 管理后台优化与安全修复

本轮范围：管理员后台、其管理接口、HTTP/Socket 身份校验、供应商配置和积分赠送。

## 已修复

- HTTP 请求使用数据库中的当前角色与状态；删除、封禁、降权后不能继续依赖旧 JWT 获得权限。密码变更递增 session_version，使旧登录失效。
- 去除根据文件扩展名放行 API 的规则。数据库管理、平台提示词、技能、模型映射、记忆配置和开发配置均要求管理员身份。
- Socket 建连、聊天和切换上下文检查账号状态、维护策略、项目与剧集归属，拒绝跨项目 isolationKey。
- 供应商凭据脱敏，脱敏占位符不会覆盖已有密钥；模型拉取走服务器，不再让浏览器携带上游密钥请求。
- 管理后台远程模型目录/代码下载禁止私网、元数据和保留地址，DNS 校验绑定实际连接，拒绝跳转及超限响应。覆盖 IPv4 变体与 IPv6 映射地址。
- 限制供应商文件 ID 和符号链接，删除文件不再使用递归删除；读取供应商列表不会自动删除数据库配置。
- production/prod 禁止通过浏览器上传执行供应商代码、清空或恢复数据库。已有可信适配器仍可运行，由服务器部署流程更新。
- 登录与注册使用独立限流桶，限制内存条目数，来源 IP 只通过 Express 的可信代理策略解析。
- 管理员赠送积分使用稳定请求号，在事务中同时更新余额、账户及流水；相同请求重试不重复入账，失败整体回滚。批量赠送限制 100 个目标并去重，逐用户提交，重试复用批次号。
- 预扣请求号不再截断，拒绝跨用户/场景复用及非法金额；手工释放要求编号确认与原因，并记录操作人。
- 列表分页限制条数与页码；订单列表不返回完整支付回调，任务列表不加载完整任务负载。
- 注册、赠送积分、维护模式使用真正的服务端配置，配置读取短缓存并合并并发查询。
- 管理页按需加载、保存导航页签、卸载时移除监听；修复断网错误处理、供应商重复点击和列表请求乱序覆盖。
- 移除虚构健康指标与未实现的全局语言/表格设置；展示实际请求状态、更新时间和真实任务状态映射。

## 验证

- 后端 TypeScript 检查。
- 前端 Vue TypeScript 检查。
- 管理安全、积分赠送、支付基础规则共 9 个回归测试。
- 积分测试在独立内存 SQLite 中模拟 8 个并发重试、金额冲突、不存在账号、写流水失败回滚及冻结余额保留。
- Vite 生产构建输出到临时目录，未覆盖现有部署静态文件。

## 部署行为变化

- 使用 NODE_ENV=production 或 prod 启动；首次初始化必须设置至少 12 位且非默认值的 XOI_ADMIN_PASSWORD。已有账号密码不会被环境变量自动替换。
- 数据库初始化完成后才开始监听；旧库自动添加 session_version，默认 0 兼容已有令牌，改密码后旧令牌失效。
- 管理员积分赠送接口新增必填 request_id（UUID）；前端已同步。批量调用失败后用相同批次号重试，已成功的目标不会重复领取。
- 数据库清空接口改成 POST 并要求明确确认，且生产环境禁用浏览器清空/恢复。
- 密钥只写不回显；编辑时保留占位符代表不修改，清空输入代表清除凭据。
- 反向代理部署时将 XOI_TRUST_PROXY 设为可信代理地址/CIDR，XOI_ALLOWED_ORIGINS 可限制允许的前端来源。
- XOI_ALLOW_PRIVATE_UPSTREAMS=true 会显式放开后台模型目录/代码下载的内网限制，只在确有可信内网模型服务需求时配置。
- 普通 JSON 默认上限 25MB，管理/登录/供应商接口单独限制 1MB，表单默认 2MB；媒体上传需求可通过 XOI_JSON_LIMIT 调整普通 JSON 上限。

## 验证边界

这不是对整个系统“无漏洞”的保证。本轮没有调用真实上游生成/支付接口，没有对线上服务器做渗透或并发压测，也没有完成全部创作接口、文件服务与第三方依赖的全面审计。

生产构建仍提示既有公共包较大；按页加载可以减少后台启动开销，不能替代实际服务器负载测试。当前限流是进程内实现，多进程部署需共享限流存储或在网关配置统一限流。
