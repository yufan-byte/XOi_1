# 画布流畅性、跟拍与运镜复用

日期：2026-10-17。范围：智能创作进入画布、灵感工作流复刻、3D 前后跟随。发布入口仍为本地 10588。

## 本轮已实现

### 智能创作 → 画布

原先在进入编辑器前等待模型目录，随后每次带需求进入又重载 iframe。现在输入框获得焦点时预热现有画布工作区；发送通过同源消息交接，复用同一 iframe。预热不创建项目、不调用模型。新需求单独建项目，按项目 ID 重挂编辑器，避免上一个项目的草稿和节点混入。

编辑器先展示，后台核验所选模型。模型同步有 10 秒超时，失败可重新同步；不可用时保留需求、技能和附件为可编辑草稿，不自动改用其他模型。恢复后使用所选模型，沿用原有费用确认与预算保护。

仅显式 handoff 才消费需求，普通打开或新建画布不应偷偷执行旧缓存需求。没有入口数据时也会释放宿主加载遮罩。

### 灵感工作流尺寸

原作品部分配置节点只有 200 × 120，容不下当前生成组件。导入和旧项目恢复时，配置卡片至少为 560 × 360，拖动缩小时也遵循此下限。扩大后移动右方和下方相邻节点，并扩展所属分组；保留提示词、媒体、模型、分组和连线。

不覆盖原作品的内容，不自动执行生成，不把缺失源素材伪装成已生成素材。文字卡片仍保留可滚动阅读。

### 前后跟随

“跟随”表示相机保持相对人物的位置，沿人物已有路线运动。旧逻辑在人物没有位移时仍生成重复的机位，造成时间线播放但画面静止。

现在检查人物位置是否实际变化；只有姿势变化不算走位。没有移动路线时，禁止添加普通跟随镜头，说明先记录起点与终点。未锁定人物还可选择“添加示例走位并跟拍（本地免费）”：人物沿朝向行走两米，相机同步跟随，添加一个独立镜头，原镜头和其他物体保留。支持返回编辑和撤销。

重复的相机关键帧不会再被显示成正在运动；静态画面显示“静态镜头 · 当前构图”。

## 运镜资产：建议下一阶段做“我的运镜”

以下是设计方案，尚未交付收藏功能。

有必要保存用户认可的 AI 或手动镜头路线，尤其是常用广告推进、人物登场、跟拍。第一阶段放在导演助理“运镜预设”内，分“内置 / 我的”，无需增加一个独立资产中心页面。

建议闭环：应用并试播 → 收藏运镜 → 命名 → 下次选择主体 → 看路线和构图 → 添加为独立镜头 → 可撤销。收藏应同时支持改名、复制和删除；删除收藏不删除已应用的镜头。

保存内容：版本、名称、缩略图、时长、焦距变化、归一化时间、相对主体的机位与视线、参考朝向与尺寸、是否依赖人物走位、来源（AI / 手动）。不把源人物 ID、场景私有资源或生成授权一起带入。

复用默认相对主体适配：将参考主体的位置移到新主体，按朝向旋转路径，按主体尺寸做有限缩放。保留“原场景绝对机位”作为高级选项，明确不适合跨场景。依赖走位的模板在新主体没有路线时必须提示补充或选择示例，不能制造静止预演。

数据建议复用现有账号隔离的工作区文档存储，增加 motion 类型及 schemaVersion；服务器校验所有者、坐标范围、关键帧数量与路径时序。缓存本地可支持离线预演，但收藏应由云端同步，不能只靠 localStorage 冒充个人资产库。

收藏、套用、试播和撤销只处理本地几何，不调用模型、不扣积分。重新要求 AI 改路线才进入独立费用确认。缩略图仅取已有白模截图，不暗中生成媒体。

验收边界：跨账号不可读写；换主体、方向和尺度后构图合理；没有人物路线时拦截；复用和撤销零模型请求；原工程不被收藏/删除覆盖；升级旧版本可恢复。

## 本轮验证

- 共享运镜与布局逻辑：10 项通过。
- 主站 Vue 类型检查、主站及画布生产构建通过。
- 实际浏览器运行主站和 React 画布：预热、发送、二次发送、不可用模型草稿、模型恢复后的费用确认取消、复刻配置完整可见，通过。整个过程只请求一次画布 index，没有真实模型或授权提交。
- 实际 3D 引擎：缺少路线时拦截；示例人物与相机在 1.1 秒观察窗口内都移动约 0.49 米；只新增一个镜头；返回与撤销通过；零模型和授权请求。
- 原导演台生命周期 15 项回归、原导演方案带入画布回归通过。
- Atelier 常规 tsc 存在原有的 Vite 双源码别名类型解析问题，本次未将其称作类型检查通过；生产构建与实际浏览器覆盖本次改动。

浏览器 API 使用隔离的账号、模型与账单夹具；3D 引擎、画布组件、跳转、参考截图和交互实际运行。本轮没有再次调用真实收费或免费模型。
