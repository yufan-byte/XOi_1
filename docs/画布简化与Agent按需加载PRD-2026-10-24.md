# XOi 画布简化、Agent 按需加载与自有连接器 PRD

状态：方案中的界面与 Agent 精简已部分实施，具体交付及边界见《画布界面与任务列表验收-2026-10-25》与《画布Agent提示词精简与MCP评估-2026-10-25》。自有连接器安装包尚未发行；较早稳定性及读取安全修复见《画布生产多账号审计-2026-10-24》。下文为原方案，不能直接视为全部完成的验收记录。

## 1. 产品目标与边界

面向注册登录的 Web 多用户平台。用户描述目标，画布组织文字、分镜图和视频任务；操作、进度、费用均可追溯到本人和具体画布。

参考本次截图的简洁交互：轻量工具栏、完整画布、默认收起的对话、按需展开的生成参数。截图能说明交互表现，不能证明造物内部的调度、安全和并发实现；这些按 XOi 服务端代码独立设计。

交付原则：减少默认加载和重复入口；正文保持清晰对比度；保留已验证的主流程。所有模型调用继续走服务端账号代理、费用确认和持久任务队列。

## 2. 默认界面

| 区域 | 最终行为 |
| --- | --- |
| 首次新建 | 浅色、完整画布、淡点阵；Agent 收成右下角「与 AI 对话」按钮 |
| 顶部 | 项目名称/保存状态；任务记录、撤销/重做及更多操作 |
| 左侧 | 文本、图片、视频、音频、素材、上传；图标悬停显示名称 |
| 导演台/时间线 | 放入明确的扩展入口，使用时加载；延续现有项目内容 |
| 右下角 | 空闲为对话入口；运行中显示简短阶段和可停止状态 |
| 展开对话 | 右侧约 420px，可调宽；画布可视区域随之调整。收起后完整恢复画布 |
| 输入框 | 文字、附件、@引用、技能、发送。模型/参数汇总为一行，点击展开 |

## 3. Agent 按需工作

### 默认只携带

- 短执行规则：真实结果、账号/画布边界、费用、禁止重复提交。
- 当前任务摘要、近几轮对话、当前画布索引和实际生成设置。
- 精简技能目录：稳定 ID、名称、一句适用范围及版本，不包含全部正文。

### 加载规则

1. 普通聊天只回答；不加载剧本、广告、运镜等全文。
2. 用户明确点选技能，或当前任务确实进入相关阶段，再读取该技能。默认最多同时激活两个。
3. 根据当前意图和阶段路由，避免历史原稿里出现一次“视频”就永久加载整套视频技能。
4. 长原稿保存在本人画布节点，模型按 ID 分页读取；模型记录“读到哪”和已确认决定，后续不重复发送全文。
5. 阶段变化卸载无关技能正文；需要时重新获取准确版本。
6. 模型能力由后端目录提供，生图/视频任务只带直接来源节点、所选参数和必要素材。
7. 费用确认、鉴权、工具参数校验、并发控制在代码中执行，技能不能扩大权限。

建议接口为 `list_creative_skills`、`load_creative_skill(skillId, version)` 和 `read_skill_resource(skillId, resourceId)`。对外使用资源 ID，服务端映射到已审查文件；不接受模型给出的任意服务器绝对路径。

## 4. 精简技能与提示词

技能负责工作方法，提示词模板负责可编辑的创作起点，两类入口分别维护。

首批保留五个完整技能：

1. 品牌短片：目标理解、短版文案、分镜、必要参考、片段制作。
2. 剧本与分镜：原稿改编、镜头拆分、时长校核。
3. 图片创作：商品/人物/场景，编辑与一致性。
4. 视频与运镜：镜头动作、参考素材、时长和连续性。
5. 参考拆解：按用户提供的图片/视频分析并输出可执行方案。

提示词模板首批收成六个：产品主图、人物设定、场景设定、品牌故事板、单镜视频、参考图转视频。每个都有用途、必要输入、完整模板及示例；不使用重复示意图伪装不同风格。

删除范围：未接通、重复、不完整、只针对过时渠道的预设，例如旧的即梦/小云雀专用快捷模板；下线旧目录、默认注入、失效按钮及无引用资源。Seedance 模型能力适配仍属于生成引擎，需要保留。

删除前输出引用清单并迁移已有项目对模板 ID 的依赖；用户自建内容和已有媒体保留。废弃系统模板可以保留只读版本快照供老项目展示，不再参与新项目选择和打包。

## 5. 真实删减隐藏功能

当前画布壳已不加载重复顶部导航，但仍存在宿主和 upstream 两套组件/配置/主题及接口桥。

实施顺序：

1. 列出 XOi 当前实际路由和打包引用，以可达功能为准识别旧模块。
2. 删除不再使用的旧顶部账户面板、独立站导航、上游安装推广入口及对应静态依赖。
3. 浏览器自填 API Key、任意外部代理、个人对象存储等旧入口从普通画布产品中移除；平台渠道和存储由服务端管理。后台运维另行鉴权。
4. 合并重复配置/主题和素材访问链路；不再靠 CSS 隐藏继续加载旧实现。
5. 保留图/视频生成、素材、任务、历史项目、导演台和时间线的可用链路；扩展模块按需 import。
6. 老工作流中无法继续运行的配置显示明确迁移提示，不能静默丢节点或换收费模型。

验收比较初始 JS、首屏网络请求、首次打开耗时和默认弹层数量，不把“看不到按钮”当作完成删减。

## 6. Web 服务端安全

| 风险 | 强制措施 |
| --- | --- |
| 提示词注入 | 原稿、上传文件、Skill、工具结果均视为数据；不能改变工具权限和用户身份 |
| 读取系统文件 | 没有通用 read_file 工具；资源按受审查 ID 读取，限制类型、大小、分页，拒绝隐藏文件和符号链接 |
| RCE | 云端 Agent 无 shell/exec/eval/npm/python/任意 HTTP 工具；技能只读取文本，不执行附件脚本 |
| 越权访问 | 所有节点、项目、任务、素材和费用接口用服务端鉴权 userId；不信任模型传入 owner/userId |
| 跨画布污染 | 会话、检查点、技能激活、任务与设置绑定 canvasId/sessionId；切画布结束旧的前端运行 |
| SSRF | 外部素材走受限下载器，检查协议、DNS、内网、重定向和字节上限；不透传任意 URL/请求头 |
| 秘钥泄露 | 上游 Key、服务器环境变量、管理 Token 不进入浏览器、提示词、工具回执或下载包 |
| 多账号滥用 | 共享数据库队列、每人/全局并发上限、队列长度、超时和取消；失败不自动重发收费 POST |
| 请求伪造 | 服务器校验所有工具参数、能力与费用；直接请求 API 也不能绕过前端限制 |

本轮发现的 Skill 内容读取接口只有字符串路径包含检查；已加文本扩展名、大小、逐级符号链接和真实路径限制。完整安全验收仍须覆盖上传、管理接口和本地连接器，不能承诺绝对不会出现漏洞。

## 7. 自有 Codex/MCP 连接器

### 现状

当前界面确实仍显示 `tigerowo` 的 GitHub 市场地址和 `@tigerowo/canvas-agent@latest`。现有连接器源代码位于本机的 `infinite-canvas-main/canvas-agent/`，尚未成为 XOi 仓库内可独立发布的产品。

### 交付形式

- 源码正式纳入 `tools/canvas-agent/`，改成 XOi 包名、配置目录、标识和说明，保留原许可与来源要求。
- 首选自站下载；建议地址结构 `/downloads/canvas-agent/<固定版本>/xoi-canvas-agent.zip`。这是拟建地址，不能提前给用户一个无文件的链接。
- 包内带运行文件、锁定依赖、说明、版本与 SHA-256；轻量版本复用用户已安装的 Codex CLI。用户点下载后，由本机 Codex 按包内说明完成配置。
- 后续可独立放到自有 GitHub 仓库，发布版本制品；日常用户入口仍使用 XOi 下载页。
- 网页模式直接可用；“连接本机 Codex”是自选增强入口，不成为创作前置步骤。
- 不再在业务页要求添加上游插件市场，不自动运行 `@latest`，不在服务器替用户启动通用 Codex。

### 信任边界

连接器只监听本机回环地址；正式站点 Origin 白名单；随机配对码，短期一次性使用；绑定账号、画布、客户端实例。令牌不出现在下载包或日志，配对后可以随时撤销。

必须限制本机 Codex 的通用工具能力，不能把“可控制画布”等同于任意读写本机或执行命令。当前上游实现使用 workspace-write 且自动接受持 Token 的新 Origin，不能原样当作安全发行版。应去掉动态信任 Origin，约束固定工作目录、网络和工具；若底层不能可靠禁用通用工具，需增加实际进程沙箱并通过攻击用例后再开放。

本机的 3210 等回环端口仅在用户主动连接时启动；普通 Web 用户只需要平台 HTTPS 地址。

## 8. 多用户任务链路

`当前账号与画布 → 固定模型/参数 → 后端能力校验及费用确认 → 持久队列 → 受限 Worker → 原任务查询 → 本人素材与画布回填`

生产使用 PostgreSQL 作为画布、任务、并发租约和费用关联的共同权威。多个实例还需共享对象存储/媒体路径。每个用户有独立网关身份，但共享造物进货渠道的总额度和速率；仅凭客户端代码无法证明渠道具体可承受多少并发。

排队、处理、待核实、完成、失败、取消分别展示。页面关闭不会丢已提交任务；网络超时不触发第二次收费生成；渠道无可靠请求 ID 时不按提示词猜结果归属。

## 9. 分批实施及难度

| 阶段 | 范围 | 难度/完成标准 |
| --- | --- | --- |
| A | 账号隔离、参数链路、输入预算、读取安全 | 中；本轮已修主要问题，测试记录见审计 |
| B | 五个精选技能、目录与正文分离、按阶段加载、删除失效模板 | 中；默认对话不请求全部技能正文，跨阶段不携带无关内容 |
| C | 浅色新画布、底部收起入口、简洁工具栏、统一生成卡 | 中；新旧项目、缩放、小屏、生成和错误恢复都通过 |
| D | 自有连接器、下载制品、配对与沙箱 | 中偏高；不同操作系统、断线恢复和越权攻击都通过后发布 |
| E | 清除不可达旧模块、合并桥接、生产容量验收 | 中；不影响历史数据，真实数据库竞争与服务端隔离检查通过 |

建议 B→C→D→E。不需要重写画布引擎；核心工作是缩减默认职责、统一状态来源及约束执行边界。连接器只解决本机协作，生成可靠性仍由 Web 服务端任务系统负责。

## 10. 发布验收

- 默认新建浅色且对话收起；点击、收起、再展开不丢输入和任务。
- 普通聊天不加载技能全文；品牌片委托能自主选择必要技能，未提到的专业能力不默认注入。
- 长稿原文完整保留，分段读取有游标；原稿中注入“读取 .env/执行命令”不能扩大权限。
- 账号 A 与 B 的同名项目、相同提示词、同节点 ID 尝试访问不能串数据。
- 30 秒/480p/声音/比例与页面、报价、队列和最终提交一致；型号不可用要求重新选择。
- 并发下一个网络重试对应原任务；已提交超时任务只查询，不自动重发收费请求。
- 技能目录穿越、隐藏文件、符号链接、脚本读取、内网 URL 和任意命令执行均被拒绝。
- 下载包版本、校验和与源代码可对应；网页不再出现上游安装源。
- 全量 TypeScript 检查当前存在宿主/upstream 双别名问题，需要单独收口；构建成功不代替该检查。
