# 交付前积分与 NewAPI 计费审计

## 交付结论

不能把本地免费测试环境直接当生产交付。用户已确认：本地保留 Agnes 免费测试，生产全部走造物。

本轮未调用任何真实收费生成接口，没有修改余额、历史账单或售价倍率。经用户明确批准，下架不兼容型号并刷新造物渠道目录与成本价；Agnes 测试渠道的型号列表保持不变。后续预算检查发现其本地网关默认定价并非零价，用户额外批准仅将本地 11 个 Agnes 型号改为按次零价，旧值已备份。已部署收费确认、任务预算与费用回执；真实生成、异步失败退款、实际售价仍需另行获得授权后完成真实验收。没有付费验收，不应承诺结算已经百分之百正确。

## 唯一账本与真实链路

`页面 → XOi 鉴权 → 当前 NewAPI 用户专属令牌 → 本方 NewAPI 渠道 → 造物上游`

- 账本是本方 NewAPI 的 `users.quota` / `logs`，不另建扣款账本。
- 500,000 quota = 1 元 = 10 积分。旧 `getActionPoints()` 返回 0 是本地不重复扣减，不代表模型免费。
- 管理员也不能假定免费；真实用量由网关按用户令牌结算。
- 价格同步、用户分组倍率与参考视频 ×1.5 仍沿用既有规则，本次不改利润比例。
- 用户请求不会借用公共管理员模型令牌，令牌保留在服务端。

| 继承的画布图片、音频、视频、工作流、参考分析各走不同请求方式 | 原生 fetch 与 React Axios 同时覆盖，避免重复弹确认 |
| Socket 剧本／导演助手绕过 HTTP 提示 | 发送前确认；取消保留输入；生产缺少计费确认号时拒绝 |

| 生产继续展示／调用 Agnes 测试模型 | 生产目录过滤并拒绝调用；就绪探针核对默认模型和测试渠道 |
| 已有 Seedance 型号缺少任务计费插件，导致整批价格同步回滚 | 经批准隔离 8 个明确不兼容型号，同步其余 181 个模型；保留旧合法计费记录，不伪造免费表达式 |
| 最近价格同步失败，状态仍显示历史成功 | 记录最近尝试状态与错误；生产探针拒绝失败或超过一小时未成功刷新的价格配置 |

## 收费入口覆盖表

共用清单：`shared/billableOperations.ts`。POST 生成属于收费入口，查询、轮询、上传、保存、导出、本地抽帧不属于收费入口。

| 区域 | 收费操作 | 用户看到什么 |
| --- | --- | --- |
| 小说 | 导入并自动分析、重新分析章节 | 模型、单次参考价、批量章节提醒、确认按钮 |
| 剧本 | AI 正则识别、提取素材、Socket 剧本创作 | 文本模型与费用确认；Agent 多次调用提醒 |
| 素材／角景 | 单张／批量生图、单条／批量优化提示词、AI 匹配音色 | 当前模型与报价；批量不能伪装成一条费用 |
| 分镜与图像编辑 | 批量分镜生图、剧集素材图、生成编辑图 | 图片参考报价与收费确认 |
| 镜头工作区 | 单条／批量视频、视频提示词、批量提示词 | 时长／清晰度报价参考与多项收费提醒 |
| 导演助手 | Socket 对话、AI 导演方案 | 模型调用确认，非本地 3D 编辑收费 |
| 智能创作 | 进入画布本身不收费；后续 Agent／参考分析调用收费 | 对真实模型请求确认，而不是对跳转扣费 |
| 无限画布 | 对话、生图、AI 编辑、视频、音频、工作流生成 | 同一确认与回执机制；常用模型预估仍保留 |
| 爆款复刻 | 文本／视觉分析、生成故事板、提交视频 | 原有阶段确认保留，并由统一请求层兜底 |
| 模型测试 | 真正调用模型的测试 | 明确“会产生用量”，并非连通性免费探测 |

素材上传、二维码上传、普通剧本保存、时间线编辑、下载导出、视频任务轮询不弹收费确认，也不额外扣一次。

## 前后提示与账单回执

- `/api/billing/preview` 根据真实路由选择模型；旧文本辅助接口使用服务端 `universalAi`，不能拿页面传来的图片模型冒充文本价格。
- 明确“本次参考预估”或“单次调用参考”。Agent／批量可能使用文字、图片、视频等多种模型；单次参考不能视作总价。
- 图片／视频输入 Token 无完整可靠估算时明确提醒；未知报价不是免费。开发环境明确显示未知，生产环境无法取得可靠报价时阻止提交。
- 预览接口失败时拦住调用，不默默继续。取消时不发送请求；重生成也要重新确认。
- 已确认请求携带随机计费关联号，贯穿 HTTP、Socket 和深层供应商请求。
- 当前网关真实返回头为 `x-oneapi-request-id`，同时兼容 `x-request-id`。仅做请求关联，不修改网关额度。
- 新增 `xoi_billing_links` 元数据表，将关联号、当前用户、网关请求号绑定；不存提示词、素材、账号令牌。
- 回执查询同时按用户与请求号关联 `logs`，不用并发时可能混入其他请求的余额差来猜测实扣。
- 未记账显示“结算中／待核对”；已入账显示“账单已记录消耗 N 积分”。批量不是最终单笔，继续查询后续用量。
- 查询最长覆盖约七分钟，长任务或刷新后的最终结果仍以跨设备可见的积分明细为准。不能把任务提交当作已完成或已退款。
- 费用通知触发宿主余额刷新，画布 iframe 同源通知宿主；切换账号后停止旧账号通知。

## 正式交付前仍须完成

1. **生产配置切换**：本地只读检查发现 17 个 Agent 默认均为 `newapi:agnes-2.5-flash`；其中 `ttsDubbing` 也指向文本模型，不能当成正式 TTS 配置。生产库需改为相应造物文字／音频模型，项目默认图片／视频也要检查。
2. **关闭生产 Agnes 测试渠道**：本地仍保留测试渠道，这是用户明确要求。生产必须用独立配置／数据库，不在本地直接关闭来冒充生产已切换。
3. **生产门禁**：`node ops/production-billing-check.mjs` 是只读检查，有测试默认、缺少可用生产渠道、价格最近同步失败或超过一小时未成功刷新时返回非零；生产 `/api/readyz` 也会拒绝就绪。当前本地检查未通过生产门禁，原因仍为 Agnes 测试配置，属于预期的测试环境状态。
4. **真实计费验收未做**：需要授权后用受控小额请求核对每类模型、参考视频 ×1.5、分组加价、停止流、异步失败、退款和重复提交。模拟测试不能代替这项。
5. **任务预算已补齐，真实账单边界仍需验收**：已增加每轮服务端预算、并发保守预留、有限额令牌、20 次调用／4096 输出 Token／30 分钟有效期和停止入口。未知上游成本与未验证多模态 Token 接口暂时拦住。详见《任务预算与自动停止-2026-10-13》；不得把模拟验证或单次参考价当作所有上游的最终账单封顶保证。
6. **退款政策与运营能力**：网关或上游失败是否退费需要真实账单核对；兼容层 `refundPoints()` 是空操作，不代表退款成功。不要对客户承诺“失败一定自动退款”。
7. **未支持的特殊模型**：目录原有禁用的超分、口型、克隆等专用接口继续不对用户开放；不能仅因为上游模型名存在就承诺可用。
