# 画布与剧本工作区优化验证

日期：2026-10-11。范围：无限画布、影视创作项目、原始素材、AI 改编及剧本创作助手。保留已有项目、素材、模型、技能、设置、创作和流水线功能。

## 无限画布

画布路由改为按需加载。列表页不再提前加载完整节点编辑器、导演台、图片/视频工作台、提示词页以及仅在其他页面显示的账户导航。模型配置在后台同步，列表先显示；打开编辑器以及执行 AI 对话交接仍等待模型同步。用户身份验证仍先于全部用户存储模块，保留账号隔离。

素材选择器只在对应入口加载；宿主新建、媒体导入、广场复刻和对话交接的桥接模块只在需要时加载。iframe 加载状态改用当前路由挂载后的就绪消息，启动失败和路由加载失败均有重试入口。

本地隔离 Chrome、模拟身份/API、相同 4 秒模型接口延迟下，实际请求脚本体积从 **3,026,926 字节降为 1,069,261 字节（减少 64.7%）**。列表显示时模型接口尚未完成，且未请求编辑器主模块。优化后一次本地首屏记录约 1.95 秒；机器负载、缓存和 API 响应会影响时间，因此不将该数值作为所有环境的速度承诺。

已验证：列表显示、新建并进入编辑器、宿主侧栏新建直达、广场图结构复刻及返回入口、主站加载遮罩正常结束。测试使用隔离本地存储和模拟接口，没有操作真实用户项目或发起付费生成。

## 项目与素材

- 新建项目按钮移到介绍文字和项目计数下面，取消绝对定位，不再压住右侧装饰卡片；保持两个新建入口与完整参数弹窗。
- 素材页缩短标题与流程介绍，给表格更多空间；保留导入、批量删除、事件分析、搜索、预览、编辑和分页。两个后续创作分支保持可用。
- 导入、编辑组件按需挂载；弹窗宽度和内容滚动高度适应小屏。

## 剧本创作助手

- 收紧页面标题、助手标题和欢迎区；重新处理组件实际输入容器的边框、阴影和内边距。
- 输入区从 3 行起，随长文本自动展开，最多 7 行；提示 Enter 发送、Shift + Enter 换行。
- 保留模型选择、积分估算、技能选择/删除、思考设置、重连与全部记忆清理操作、发送/停止、工作区标签、编辑及采用剧本等功能。
- 下一步导航进入正常布局，避免覆盖工作区；窄屏将稿件与助手上下排列。
- 手机侧栏默认图标栏，可展开；桌面用户的侧栏偏好继续保留。手机顶部项目快捷入口可横向滚动。

隔离浏览器验证了 1440、1000、390 像素宽度：项目按钮不与装饰重叠，新建及导入弹窗不越界，输入区可增长，技能可选择/保留，四个设置操作仍在，页面无运行时错误。实时连接使用测试身份，不能据此评价真实模型生成速度。

## 构建与检查

最终产物已同步到 localhost:10588。该生产站的 1440、1000、390 像素界面回归通过，新建、复刻和 iframe 就绪消息验证通过。Vue 类型检查通过；Vue 与 Atelier 生产构建通过。Atelier 独立 `tsc` 检查仍有上游目录的别名/类型错误（例如上游 `@/` 解析到另一套本地 store，及 `next/navigation` 的类型缺失），本次修改的 main/router/layout 文件未报告类型错误；Vite 的上游适配插件和实际生产页面验证通过。此处保留该限制，不把全项目类型检查描述为全部通过。
