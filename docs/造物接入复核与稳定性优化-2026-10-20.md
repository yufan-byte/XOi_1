# 造物接入复核与稳定性优化（2026-10-20）

## 结论

接入前半段已经完成，但原同步器仍按“单一造物渠道”设计，与当前 NewAPI 的多分组渠道结构不匹配。数据库只读核查显示：

- `zaowu-xoi`：3 个 XOi Seedance 专用型号；
- `zaowu-default`：185 个型号；
- `zaowu-claude-kiro`：7 个型号；
- `zaowu-claude-official`：9 个型号；
- `zaowu-gpt-pro`：6 个型号；
- `zaowu-gpt-pro-enterprise`：4 个型号。

旧同步快照只有 `zaowu-default` 的 185 个型号，原因是代码只读取第一个 `tag=zaowu-all` 的渠道。XOi 专线虽然已存在于 NewAPI，但未纳入同一套价格与能力快照。

## 本次修复

1. 多分组同步
   - 自动同步全部启用的 `zaowu-*` 渠道；
   - `zaowu-xoi` 使用 `xoi` 进货倍率，`zaowu-all` 使用 `default`，其他分组按标签映射；
   - 公共价格与能力卡按上游地址复用请求，各渠道的 `/v1/models` 仍按各自令牌求交集；
   - 所有价格选项与渠道目录作为一个事务式批次处理，部分失败时回滚已修改的价格和渠道目录；
   - 同一型号若意外存在于多个进货分组，采用最高进货倍率，避免渠道顺序导致倒挂亏损。

2. XOi 业务模型与上游目录解耦
   - 项目和 Agent 保存的模型名只表示“偏好”，不再因一次渠道上下架而永久改写数据库；
   - 调用时优先使用原型号；暂时不可用时选择同家族、同类型、推荐优先的健康型号；
   - 原型号恢复后自动回切；
   - Agnes 永远不会成为普通业务模型的自动兜底。

3. 推荐排序
   - XOi 固定运营推荐优先：
     1. `seedance2.0-line1-xoi`
     2. `seedance2.5-line1-xoi`
     3. `seedance2.0-line1-fast-xoi`
   - 造物卡片的 `primary`、`featured`、`pin` 作为次级推荐来源；
   - 推荐信息只影响展示与默认选择，不覆盖价格、模型 ID 或计费表达式。

4. Agnes 管理员测试隔离
   - 管理员可在生产环境目录和管理测试入口看到 Agnes；
   - 普通用户的模型目录、报价、Socket 入口、画布入口以及手工构造的 `/api/v1` 请求均无法调用 Agnes；
   - Agnes 可以保留在 NewAPI 启用渠道中，但不得配置为面向全体用户的 Agent 默认模型；
   - 免费判断仍以 NewAPI 的明确零价配置为准，价格变化会自动停止“免费调用”，不会转为静默扣费。

## 验证

- 后端测试：258 个测试，257 通过，1 个按环境跳过，0 失败；
- 新增覆盖：模型偏好临时回退与恢复、Agnes 不参与业务兜底、上游重点推荐低于 XOi 固定推荐；
- 类型检查：本次修改无新增错误；仓库仍有既存的 `src/utils/director/workflow.test.ts` 使用 `import.meta` 与当前 TypeScript `module` 配置不匹配的问题；
- 本次没有调用任何图片、视频、文本或音频生成接口，没有产生模型费用。
