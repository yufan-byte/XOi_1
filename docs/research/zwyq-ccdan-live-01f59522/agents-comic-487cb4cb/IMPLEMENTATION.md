## 产品入口

`localhost:12121` 原工作台内：“剧本创作” → 原标题栏内切换“快速创作 / 导演创作”。没有第二套二级菜单、没有独占一行的模式栏。运行包按需加载在同源右侧内容区，和无限画布的工程隔离方式一致。

## 来源和改动

- 基准为用户提供的 `zaowu-engine-main/src/components/agents/comic` 原源文件/CSS，及 multiframe 视频能力、语音预设等纯客户端辅助文件。
- 原图样式、输入/精品剧/批量剧、模板、阶段工作台、资产库结构复用；登录、模型目录、价格、存储换成 XOi 适配器。
- 初版仅复制两张 WebP；按用户后续要求，已恢复原包两段本地 MP4（842,279 字节）作为悬停预览。不复制原站账号、上游密钥。当前独立产物合计 1,798,937 字节，其中非视频 956,658 字节。视频初始没有 src、preload=none，交互时才加载，不是首屏强制下载。
- 原线上链接本轮没有稳定显示漫剧主体，不能宣称完成了在线逐像素对比；本地提供的源码是主要依据。风格预览仍沿用提供源码中的配色缩略，不假称真实生成样例。

## 已实现

- 使用当前 XOi 登录态，服务端按身份过滤独立 `xoi_one_stop_documents` 表。
- 项目、风格服务端保存，列表分页、按 ID 读取，账号切换隔离；不依赖浏览器永久存项目，不按用户数清空。
- 乐观并发版本；创建要收到服务器回执才能跳转，快速编辑合并写入；冲突或未知保存结果保留本地副本，禁止自动覆盖/重复提交，可下载待核对 JSON。
- 删除为软删除，数据库保留内容和编号；本轮尚无回收站恢复界面、历史版本浏览界面。
- 模型目录使用 XOi 公共目录及统一积分格式，1 元 = 10 积分，不直连造物浏览器 Key。
- `one-stop-only` / `main-only` 独立发布保留旧哈希资源，避免发布暂缓的团队页；Docker 构建与发布预检查纳入一站式入口。未实际构建生产 Docker 镜像。

## 验证证据

### 2026-10-20：后端生成链路（取代上述初版关闭状态）

已接入 XOi 后端报价、预算、持久化队列与积分回执；不再执行复制来的浏览器自动循环。单步文字、素材图、分镜图、镜头视频、配音、批量图片/视频以及连续制作均通过 owner-scoped 任务。免费任务不让用户输入预算，收费任务明确确认额度；预算到顶、20 次实际调用上限、输出 Token 上限和到期都会停止后续请求。后台任务按项目/账号恢复，未知结果锁定，不自动重发。管理员可用 `XOI_ONE_STOP_GENERATION_DISABLED=1` 暂停新请求及后续步骤。

每步以任务租约和文档 revision 双重校验原子保存；重生成前的值保存在独立历史表，不事先删除后续成果。精品剧完整规划，批量剧从系列设定直接进入剧本。视频报价和请求统一读取项目实际清晰度、时长；新增备选帧不会替换主帧。全部镜头齐备后才能标记项目完成，不把部分成果宣传成完整成片。

本轮验证：38 项生成/计费/存储单测，另有原资源权限回归；12 组本地随机 schema 隔离测试；并行队列、租约、幂等检查；页面 fixture 验证免费无预算输入、确认前零提交、取消、付费预算显示、待核对锁定、人工核对、新页面恢复。真实本地 Agnes 2.5 意图分析成功，实际模型调用 1 次、预算 free_only=true、调用计数 1、回执 0 积分、checkpoint 与历史表均有记录。Agnes 2.0 的一次免费请求被上游以无可用渠道拒绝，错误日志 quota=0；没有自动切换收费模型。未调用造物收费模型。临时验收项目采用软删除，任务与历史记录保留。
