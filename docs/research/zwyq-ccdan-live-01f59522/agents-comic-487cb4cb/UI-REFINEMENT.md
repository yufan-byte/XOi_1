# 创作模式与界面规格（2026-10-19，取代此前二级菜单方案）

> 最新消费交互已调整为“今日消费提醒，只提醒不打断”，普通生成不弹逐次预算确认；以 docs/SPEND-REMINDERS.md 为准。

用户最新要求优先：一个“剧本创作”入口，工作区内切换“快速创作 / 导演创作”，不要再叠加一整行标题或切换栏。

- 导演页：模式切换嵌入原“影视创作项目”标题卡右侧，与新建项目并排；现有项目/剧本/分镜流程不变。不新增顶部占高栏，窄屏才自然换行。
- 快速页：模式切换嵌入已有的“项目 / 资产 / 保存状态”工具栏。同源消息须验证 origin + iframe source，只有当前活动快速页可以请求返回导演。
- 模式隔离：同一账号与积分体系，项目独立，不转换、不复制、不覆盖。宿主保留快速工作区，切换后未提交的表单仍在；返回时记住当前账号的快速路由，换账号清除导航位置。
- 默认界面：故事、风格、画幅、每集时长、可选封面、明确创建按钮。模型和地区/集数收进默认折叠的“高级设置”，文案/图片/视频可单独更换。优先采用目录推荐模型，不只是拿列表第一项。
- 基础价：复用统一积分格式，1 元 = 10 积分；模型单价不是整部作品总预算。未知价不得显示免费；切换和保存模型设置不会调用模型。
- 创建：保存精确模型 ID、时长、集数；服务器回执后才跳转。默认渐进式，不能自动启用复制来的前端托管循环。
- 风格：XOi 暖白纸感、墨灰文字、橙色强调，移除橄榄绿背景和选择面板。轻淡云山 SVG（约 1KB）仅作装饰，不载入大背景或新字体。标题不做巨幅占位。
- 精品/批量视频卡：保留本地 MP4 与 poster，悬停/聚焦加载、移出/失焦/隐藏/离屏暂停，节省流量/减少动态模式仅海报。
- 响应式：390px 折叠和展开模型配置均不能横向溢出；弹窗内部限高滚动。桌面主要动作在现有标题卡内。
- 安全边界（2026-10-20 更新）：生成改为后端持久化任务，所有入口先报价、确认预算再提交；免费模型不显示手填额度。待核对任务保持锁定，不自动重发。后台连续制作不等于已导出完整成片，全部镜头齐备才能手动标记完成；导出文件需下载保存。
- 精品/批量卡片：斜切轮廓、电影海报与悬停视频，橙色选中边框和标记；批量路线明确划掉跳过的规划步骤，手机端取消斜切，优先可读性。
- 发布：仅更新本地一站式包、按授权验证后重启 12121，保留旧哈希资源，不发布暂停的团队页面、不改生产、无收费调用。验收范围见 IMPLEMENTATION.md 的最新生成链路章节。
