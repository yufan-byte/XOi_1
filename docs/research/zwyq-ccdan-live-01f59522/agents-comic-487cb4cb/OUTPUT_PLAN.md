# XOi AI 一站式源码移植计划

- 来源：用户提供的 `/Users/zhaochenyu/Downloads/zaowu-engine-main`，页面 `https://zwyq.ccdan.live/agents/comic`。
- 目标：保留现有导演端，新增独立产品支线，不融合导演项目和漫剧项目。
- 最新入口（2026-10-19）收敛为：单一“剧本创作”导航，无二级子菜单；现有标题栏内切换“快速创作 / 导演创作”，不再单独新增顶部一行。导演仍为 `/project`，快速仍为 `/#/script/one-stop`，深链接兼容。项目彼此独立。
- UI 共享现有工作台侧栏、账号和积分区。独立 React 运行包内嵌同源右侧内容区，`embed=1` 隐藏第二套导航；主站菜单切换时保留工作区，避免中断待保存内容。独立构建是工程隔离，不是另开产品网站或端口。
- 应用根：`frontend/console` 的既有 React 构建工具；新增独立入口 `one-stop/index.html`、`vite.one-stop.config.ts`，输出 `frontend/public/one-stop`。不复用管理台入口，不发布团队界面。
- 新组件根：`frontend/console/src/one-stop/`。原版漫剧组件放 `comic/`；XOi 接口、持久化及壳适配放 `adapters/`。
- 目标路由：`/one-stop/#/comic`、`/one-stop/#/comic/assets`、`/one-stop/#/comic/:id`。Hash 子路由无需修改服务器 SPA fallback。
- 原 `/agents/comic`、`/agents/comic/assets`、项目链接在构建迁移中定向到新支线路由；不改变旧导演端路由。
- 资源根：`frontend/public/one-stop/brand`，仅复用本地所需品牌图，不下载示例大片或复制任何凭据。
- 后端：新命名空间 `/api/one-stop`，独立 PostgreSQL 表，认证身份来自 req.user，乐观并发、软删除、分页、无按用户数量清空持久数据。
- 本轮模型调用默认关闭，先完成原版页面、手动编辑、跨设备保存、独立构建与隔离验收。未接入的生成入口必须明确显示尚未开放，禁止直连旧站或静默绕过计费。
- 共享改动限于导演壳产品切换入口、独立构建和发布脚本。不覆盖现有管理台、画布、项目或公告资源。
- 临时随机端口仅用于合成账号、内存数据的隔离验收，不能作为正式用户入口、不能导入真实令牌。

## 结构与行为基准

本地原版源文件及 CSS 是移植基准；在线页面此前未稳定渲染漫剧主体，不把模型广场当成漫剧视觉参照。保留原首页创意输入、精品/批量选择、规格选择、模板、项目搜索与卡片；工作台保留阶段路径、可编辑产物和设置抽屉。点击驱动，不添加滚动自动切换。

服务器保存状态须明确：加载、保存中、已保存、失败、版本冲突。浏览器内存可以缓存，不能假称保存成功。旧结果不得因新页面加载失败被删除；版本冲突不能自动覆盖。
