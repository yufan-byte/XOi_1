# 行为记录

- Banner：点击主卡或两侧卡切换，卡片通过 transform 过渡重排。
- 分类条：点击切换激活态；当前项为深色胶囊。
- 吉祥物：WebM 自动播放、静音、循环。
- 输入器：保留现有 Enter 发送、自动增高、附件、Skills、执行模式、语音和停止生成交互。
- Skills：工具箱按钮切换弹层；点击弹层或触发按钮以外区域关闭。列表仅展示当前账户已安装项，选中路径随对话请求发送。
- 优质灵感：使用项目自有素材与原创提示词；点击卡片回填输入框并聚焦，外部入口跳转 Miora 原站灵感列表，不镜像第三方视频和完整作品内容。
- 响应式：窄屏隐藏吉祥物，分类条横向滚动，轮播主卡扩展至 82%。
