# 3D 导演助理：场景恢复与画布交接验收

实施依据：[场景与镜头交互 PRD](./3D导演助理场景与镜头交互PRD-2026-10-17.md)。已发布至本地 10588 主站与其内嵌画布，不新增开发端口。

## 最终行为

- 场景搭建/调整应用到当前镜头内的场景，不新增镜头、不自动进入相机预演；镜头设计与运镜预设仍新增独立镜头。
- 从空场搭建不混入旧人物和布景。应用前保存账号、工程隔离的撤销备份；刷新可恢复，后续手动更改使旧备份失效。
- 四个本地模板：单人空场、双人对话、桌边对谈、走位跟拍。原生坐姿动画的骨盆向后偏移已纳入椅面对齐，走位与相机共用 4 秒时间线。
- 请求是否允许重新生成与账单是否回传分开处理。确认旧授权已停止后，可主动发起新尝试；账单与原预算预留不清除、不伪造为零。停止失败不会解锁，不自动重试。
- 助理不再显示历史账单列表或调用编号，仅显示当前状态与“去积分明细”。明细在新标签打开，保留导演台。
- 带入画布按“当前机位白模参考图 → 提示词 → 视频配置”组织；配置为 560 × 360，按钮完整可见，提示词仅通过连线输入一次，各镜头使用自己的时长。多镜头初始视口聚焦第一组。
- 白模图明确为当前机位截图，不冒充 AI 镜头方案渲染或运镜录像；读取失败有可恢复提示。导入不触发模型请求。
- 内嵌原生标题不再漏到第二行；相机预览角标显示 XOi。

| 验证 | 结果与边界 |
| --- | --- |
| 后端/共享逻辑测试 | 30 项通过，包括场景范围、原内容保护、时长与主体、座位对齐、请求停止、账单状态、画布交接契约 |

| 镜头费用/时长 UI | 3 组通过：待回传恢复、4 秒时间线、刷新期间不自动提交 |
| 原有导演台生命周期 | 15 项通过：运镜、退出、Esc、清空轨道、撤销、费用确认取消/超时、导入时关闭 |
| 画布交接 UI | 真实主站和原生截图进入真实画布组件；4 个节点、2 条连线、4 秒参数、参考图可解码，生成按钮位于配置卡片内；交接没有额外授权或模型调用 |

上述故障与画布 UI 测试使用隔离账号、模型和账单响应夹具，不构成真实付费模型验证。原生 3D 引擎、渲染物体、相机、截图、导入、画布组件均实际运行。

## Agnes 真实免费验证

使用真实 `agnes-2.5-flash` 执行一次“场景只要一个人，不要别的物体”的 5 秒搭建：

- 服务端预检确认免费，授权 `freeOnly=true`，预算最多调用 1 次。
- 实际调用 1 次，50.5 秒返回有效方案；应用后 1 个人物、镜头数量不变、保持编辑视角，预演和撤销成功。
- 原授权已停止，真实网关消费日志 `type=2, quota=0`，测试前后余额一致。
- 真实积分明细页面可打开。没有发起真实收费模型或媒体生成请求。
- 此实测发生于本轮场景恢复版本；后续精简账单展示、XOi 角标和画布交接通过隔离 UI 回归验证，未再次调用真实模型。
