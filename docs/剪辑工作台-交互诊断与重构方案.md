# 剪辑工作台：交互诊断与重构方案

> 诊断对象：`/#/project` → 工作台节点 → `视频工作台` 弹窗 → 第 03 步「剪辑成片」
> 代码位置：`frontend/src/views/production/components/workbench/editVideo/`
> 结论日期：2026-10-03
> 证据口径：全部来自当前磁盘代码，关键判断均带文件路径 + 行号

---

## 0. 一句话结论

现在这个「剪辑」**在技术上是个真剪辑器，在产品上是个半成品**。

- **真**：`vue-clip-track` 提供多轨时间线、拖拽/拆分/转场/撤销，`@webav/av-canvas` 提供逐帧合成与真实 MP4 导出。底层能力是齐的。
- **半**：**它把"从零搭一条时间线"的活全丢给了用户，而用户手里根本没有"素材"这个概念——他只有"分镜"。**
  于是出现三个致命体验：进页面**主轨道是空的**（没东西可剪）、左侧素材库**认不出是哪个镜头**（名字叫 `#分镜1-1`）、导出弹窗里的**「当前范围/按场景分段」是假的**（点了没反应，永远导全片）。

> 病灶一句话：**它按"通用剪辑软件"的范式做，但用户要的是"把分镜装配成片"。**
> 剪辑能力本身不用重写，**要做的是把"进入即有事可做"这条最短路径补出来，再把假的控件变成真的。**

## 1. 它是怎么实现的（技术链路还原）

### 1.1 入口层级：三层套娃，剪辑是"第三个 Tab"

```
/project  画布（vue-flow）
  └─ 节点 workbench.vue ──「打开工作台」──┐
                                          ▼
     全屏 t-dialog（components/workbench/index.vue）
       ├─ 01 分镜预览  preview.vue
       ├─ 02 生成视频  generate/index.vue ── emit("importVideo") ──┐
       └─ 03 剪辑成片  editVideo/index.vue ◄──────────────────────┘
```

- 剪辑**没有独立路由**，只能在 `editVideo/index.vue:1-152` 这个全屏弹窗的第 3 个 tab 里。
- 唯一把数据送进时间线的通道是 `workbench/index.vue:216-231` 的 `handleBatchDownload()`——它在 **02 生成视频**页被调用，赋值 `initialVideoItems` 后 `activeMenu='editVideo'`。
  **即：不经过 02 页的"导入到剪辑台"按钮，剪辑台就没有镜头。**

### 1.2 布局：上 60 / 下 40 的双层 splitpanes

`editVideo/index.vue:13-32`

```
┌── 顶层 splitpanes（horizontal 60 / 40）───────────────────────────┐
│ 上半 60%：splitpanes（横向 20 / 60 / 20）                          │
│   [ 素材库 20% ][ 预览 60% ][ 属性面板 20% ]                        │
├──────────────────────────────────────────────────────────────────┤
│ 下半 40%：<VideoTrack>（vue-clip-track 时间线）                     │
└──────────────────────────────────────────────────────────────────┘
```

预览实际可视面积 ≈ `60% × 60%`，再被两侧面板挤掉 → **预览是整套界面里最小的一块**。而这是剪辑唯一需要"看清"的地方。

### 1.3 时间线：库给的能力 vs 用上的能力

`vue-clip-track@0.1.5` 导出（`node_modules/vue-clip-track/dist/index.d.ts`）：`VideoTrack` / `Ruler` / `Tracks` / `ToolsBar` / `ContextMenu` + `extractVideoThumbnails` / `extractAudioWaveform`。

当前用到的：`VideoTrack` + 自定义 5 个操作按钮（reset/undo/redo/split/delete）+ `scaleConfigButtons:["snap"]`。
配置块 `editVideo/index.vue:243-280`：允许 video5/image3/audio3/subtitle2/text2/sticker2/filter1/effect2。

**没用上的关键能力**：库自带 `Ruler`（可打刻度/标记）、clip 右键 `ContextMenu`、`pixelsPerSecond` / `maxDuration` 配置项。

### 1.4 自动铺轨：只有一条极窄的路径

`editVideo/index.vue:518-566` `initializeTracks()`：

```ts
// 531 行 ← 全部条件必须同时成立
if (!timelineDraft.value && mainTrack && props.initialVideoItems.length > 0 && mainTrack.clips.length === 0) {
  props.initialVideoItems.filter(item => item.selected && item.url)  // ← 只铺「已选用」的
       .forEach(item => { /* 顺序铺到主轨 */ });
}
```

而 `initialVideoItems` 来自 `workbench/index.vue:149-162`，`selected` 的判定是 `item.videoId == subItem.id`——**即"这个分镜在分镜台里被选中过的那条视频"**。

> **结论：用户在「分镜台」没逐个选视频，剪辑台主轨就是空的。**
> 这正是"时间线什么的都没有"的根因——不是时间线组件没渲染，是**时间线上真的没有 clip**。

### 1.5 导出：只有「整片」是真的

`editVideo/index.vue:289-294`：

```ts
{ value: "full",   label: "整片导出",   disabled: false },
{ value: "range",  label: "当前范围",   disabled: false },
{ value: "scene",  label: "按场景分段", disabled: false },  // ← 点了提示「正在接入」
{ value: "marker", label: "按标记分段", disabled: true  },  // ← 直接禁用
```

`editVideo/index.vue:301-323` → `videoPreview.vue:1484-1517`：

```ts
async function exportVideo() {
  const combinator = await avCanvas.createCombinator();   // ← 没传 start/end，永远全片
  ... a.download = `WebAV-export-${Date.now()}.mp4`;
}
```

**`exportStart` / `exportEnd` 两个变量被 UI 收集了，但从来没传进导出逻辑。**（`createCombinator(opts)` 只吃 `width/height/bitrate/fps/bgColor/audio/metaDataTags`，范围导出需要自己构造只含区间内 sprite 的 Combinator。）
这是当前最伤信任的一处：**用户调了入点出点，导出结果和调之前一模一样。**

### 1.6 假控件清单（已确认点了没作用）

| 控件 | 位置 | 为什么是假的 |
|---|---|---|
| 音频「淡入 / 淡出」 | `propertyPanel.vue:119-144` | `videoPreview.vue:897-946` 建音频 sprite 时**只读 `volume`，从不读 `fadeIn/fadeOut`**；`getClipSnapshot()`（`videoPreview.vue:722-733`）也不含这两个字段 → 改了连重建都不触发 |
| 导出「当前范围」 | `editVideo/index.vue:133-138` | 值收集了但没传给 `exportVideo()` |
| 导出「按场景分段」 | `editVideo/index.vue:140-143` | 显示「正在接入」 |
| 操作按钮 `import`（导入项目） | `editVideo/index.vue:238` | 在 `operationButtons` 里，但对应 `<template #custom-operation-import>` **已被注释掉**（`98-103`）→ 按钮不存在，却仍占位 |
| 「自动保存草稿」标签 | `editVideo/index.vue:9-11` | 只写 localStorage（`228-230`），**不显示保存时间、不落库、换设备即丢** |

### 1.7 其他实现细节

- **草稿**：`localStorage['xoi:timeline-draft:<projectId>:<episodesId>']`，防抖 450ms（`editVideo/index.vue:325-330`）。
- **播放头滚动 / 滚轮缩放**：**手写**（`editVideo/index.vue:568-621`），mousedown 拖拽 1.5 倍系数平移 + wheel 调 `scaleStore.zoomIn/Out(0.2)`。
- **转场**：`videoPreview.vue:296-381` `detectTransitions()` 用 **±1s 容差"猜"**前后 clip 并建立关联。
- **成片归档**：`videoPreview.vue:1519-1562`，>18MB 只下载不入库，提示 6 秒后消失。

## 2. 为什么"难受"：12 条问题清单

按严重度分三级。

### 🔴 致命（直接导致"没法用"的观感）

| # | 问题 | 证据 |
|---|---|---|
| 1 | **进入即空轨**：没在分镜台逐条选视频，主轨就是空的，且 UI 没有任何"点这里开始"的引导 | `editVideo/index.vue:531` 四条件全与 |
| 2 | **素材库认不出镜头**：名字是 `#分镜1-1` 这种编号，缩略图靠异步抽帧后才出现；顶部甚至写着"视频素材名字按照分镜台组#号数字命名"——**这是在教用户迁就实现** | `mediaLibrary.vue:6`、`workbench/index.vue:154` |
| 3 | **只有拖拽能上轨**：没有"点击加入 / 追加到末尾 / 插入到播放头 / 一键全铺" | `editVideo/index.vue:352-476` 仅 `handleDropMedia` |
| 4 | **导出是假的**：范围/分段全不生效，用户调完导出一模一样 | `editVideo/index.vue:301-323` |
| 5 | **假控件**：淡入淡出、导入项目按钮，点了没反应 → 用户会开始怀疑整个界面 | §1.6 |

### 🟠 结构性（能做但难用）

| # | 问题 | 证据 |
|---|---|---|
| 6 | **预览太小**：60%×60% ≈ 36%，且被两侧挤压 | `editVideo/index.vue:14-31` |
| 7 | **时间线高度锁死 40%**，不可拖拽调整；轨道多时挤成一条缝 | `editVideo/index.vue:33` |
| 8 | **播放时时间线不跟随**：没有自动滚动，播放头跑出视野就要手动找 | 无相关实现 |
| 9 | **无标记（marker）**：但导出里却有"按标记分段"，概念悬空 | `editVideo/index.vue:293` |
| 10 | **无快捷键体系**：拆一段要点工具栏按钮；空格/方向键/`,``.`跳剪辑点全无 | `useKeyboard` 库已导出但未使用 |
| 11 | **属性面板只支持单选**（`selected.length === 1`），无法批量调音量/时长；缺位置/缩放/旋转/翻转（clip 本身有 `rect`） | `propertyPanel.vue:237-240` |
| 12 | **手写缩放/滚动与库内建交互并存**，拖拽平移与 clip 拖拽靠 `target.closest()` 兜底，容易互相打架 | `editVideo/index.vue:573-621` |

### 🟡 细节（打磨项）

- 时间码只显示 `MM:SS`，无毫秒（`editVideo/index.vue:296-299`）。
- 头部"自动保存草稿"是死文案，无保存时间。
- 转场用容差猜关联，跨轨/相邻密集时容易指错。
- 字幕要一条条手打，**而项目里已经有 `o_script` 的分集台词**——这本该是一键导入。
- 成片 >18MB 静默不入库，用户以为存了。
- 左侧库、时间线都**没有真缩略图条**（库有抽帧但只在拖拽后加载）。

## 3. 设计原则

在动任何代码之前，先把范式定死：

| 原则 | 含义 | 反面（现在） |
|---|---|---|
| **P1 分镜是一等公民，素材是二等** | 时间线的默认内容单位是"分镜镜头"，不是"文件" | 把每个 mp4 当匿名素材让用户拖 |
| **P2 进入即有稿** | 打开剪辑台 → 自动按分镜顺序铺一条时间线，用户从"改"开始，不从"建"开始 | 空轨 + 让用户自己拖 |
| **P3 所见即所得，假的宁可删** | 控件要么真生效，要么不出现 | 淡入淡出、范围导出 |
| **P4 剪辑器是独立工作台，不是弹窗里的第三格** | 独立路由，从任何地方一步直达 | 画布→节点→弹窗→tab，四步 |
| **P5 键盘优先** | 剪辑是高频操作，快捷键是硬需求 | 全靠点 |

## 5. 时间线设计（这一块是重点）

### 5.1 自动装配（P2 落地）——解决"什么都没有"

进入 `/editor` 时，若该 `project + episode` 无云端草稿：

1. 拉取分镜镜头（`o_storyboard` + 各分镜的 `o_video`，按 `shotIndex`/创建序）
2. **按分镜顺序铺满主轨**，每个分镜取"已选视频"，没选的取最新一条成功视频
3. 顶部 toast：`已按分镜顺序铺入 12 个镜头（共 1:40），可直接精剪` + `[撤销自动编排]`
4. 空白态（一个镜头都没有）不再是一片黑：给**引导卡** ——「先去分镜台生成镜头 →」+「或从本地上传视频开始」

> 一句话：**把"从零搭"换成"改初稿"。**

### 5.2 时间线要补齐的部件

| 部件 | 做法 | 解决 |
|---|---|---|
| **播放头跟随** | 播放中让 `track-area.scrollLeft` 保持播放头居中（`requestAnimationFrame` 节流） | 问题 8 |
| **时间码输入** | 顶栏 `00:12.34` 可点可编辑，回车跳转；`|◀ ▶|` 切上/下一剪辑点 | 问题 12 |
| **标记 marker** | 标尺上 `M` 键 / 右键打点，标尺上渲染 ◆；侧栏列出标记（可跳转/删除/改名） | 问题 9，且**让"按标记导出"有真实语义** |
| **缩放/平移归位** | 删手写 wheel/mousedown；改用库 `scaleStore` + **空格拖拽平移**（行业惯例），`+/-` 缩放，`\` 适配全片 | 问题 12 |
| **轨道管理条** | 每条轨道常驻：👁 隐藏 / 🔒 锁定 / 🔇 静音 / 高度拖拽；主轨高亮描边 | 问题 7 |
| **clip 缩略图条** | 建 clip 时即调 `extractVideoThumbnails(src, {count:20})` 铺在 clip 上（库已导出，`mediaLoader.ts` 已有实现） | 问题 2 |
| **音频波形** | 已实现（`loadAudioClipWaveform`），确保渲染 | — |
| **快捷键体系** | 见下表 | 问题 10 |

**快捷键**：

| 键 | 行为 | 键 | 行为 |
|---|---|---|---|
| `Space` | 播放 / 暂停 | `←/→` | 逐帧 |
| `S` | 在播放头拆分选中 clip | `Shift+←/→` | 逐秒 |
| `Del` | 删除选中 | `,` `.` | 上/下一剪辑点 |
| `Ctrl/⌘+Z` / `Shift+Z` | 撤销 / 重做 | `Home/End` | 到片头 / 片尾 |
| `Ctrl/⌘+D` | 复制选中到其后 | `M` | 打标记 |
| `+` `-` | 时间线缩放 | `\` | 适配全片 |
| `Space`+拖 | 平移时间线 | `I` `O` | 设入点 / 出点 |

### 5.3 转场从"猜"改成"标"

现在 `detectTransitions()` 用 ±1s 容差猜前后 clip（`videoPreview.vue:296-381`）。
改成**显式挂载**：`transition` clip 记录 `beforeClipId` / `afterClipId`（拆在 `addTransitionBetweenClips` 里写入），`detectTransitions` 只读不猜。拆一次或删一次就 `nextRender` 重算。—— 这是纯数据模型收敛，**渲染逻辑不用动**。

## 6. 镜头/素材库设计

三个 Tab，默认第一个：

### Tab 1「分镜镜头」（默认）

- 卡片：**分镜缩略图**（有图用图，无图用视频首帧）+ `分镜 03` + 时长 + 提示词摘要
- 状态角标：`已上轨` / `未生成` / `生成中`
- 交互：
  - **单击 = 追加到主轨末尾**（最常用，一下就有反应）
  - **双击 = 插入到播放头**
  - **拖拽 = 插入到指定位置**（保留原能力）
  - 右键 = `插入到播放头` / `替换选中 clip` / `预览` / `重新生成`
- 顶部：「按分镜顺序全部加入」+ 搜索

### Tab 2「素材」

上传的视频/图片/音频 + AI 生成图。同样支持"点击加入"，不再只是拖。

### Tab 3「效果」

转场 / 滤镜 / 特效 / 字幕模板。转场改成**拖到两个 clip 的接缝上**（带高亮吸附），不再靠容差命中。

## 7. 预览与属性面板

### 7.1 预览

- 视频下方**真播放控制条**（现在是裸 `range` input，`videoPreview.vue:17-20`）：
  `▶/⏸` · `00:12.34 / 01:40.00` · 音量 · 比例切换 · 全屏
- 顶栏比例切换（`1920×1080 / 1080×1080 / 1080×1920`）应实时改画布，而不是只在 `workbench/index.vue:82-94` 初始化时读一次 `project.videoRatio`。
- 预览里直接拖画面 = 调 clip 的 `rect`（库已支持，`syncSpriteToClip` 已有）；选中框显示安全区（标题安全/字幕安全）参考线。

### 7.2 属性面板

- **支持多选**：多选时展示"共同可改项"（音量、透明度、时长、速度），批量生效。
- 补 `rect` 四项：位置 X/Y、缩放、旋转、翻转。
- 补字幕样式：字号/颜色/描边/位置（底部居中/顶部/自定义）。
- **删掉假的淡入淡出**，改为**音量包络（关键帧）**：音频 clip 上可直接在波形上拖点做淡入淡出——真实现，且比两个数字框好用。
- **「从剧本导入字幕」按钮**：读 `o_script` 的分集台词 + 镜头时长，按镜头边界生成 subtitle clips（项目已有数据，纯组合）。

## 8. 导出：把假的变成真的

| 模式 | 实现方式 |
|---|---|
| **整片导出** | 现状即可 |
| **当前范围** | 用 `createCombinator({width,height,fps})` 新建 Combinator，**只 addSprite 与 `[start,end]` 相交的 sprite**，且 `sprite.time.offset -= start*1e6`，`output({maxTime:(end-start)*1e6})` |

## 11. 不做什么（明确划界）

- **不重写渲染层**：`AVCanvas` + sprite + `tickInterceptor` 这套是打通的，滤镜/特效/转场都能用，别动。
- **不换时间线库**：`vue-clip-track` 够用且已深度定制（缩略图/波形/转场都接在它的 clip 模型上），换库等于重做。
- **不做多用户协同 / 云渲染**：浏览器端 WebCodecs 合成是当前架构的基石，改成服务端渲染是另一个项目。
- **不做关键帧动画曲线编辑器**：短剧场景用不上，只做音量包络（因为淡入淡出是已有需求且现在是假的）。
- **不做素材"重命名/整理"体系**：素材的语义应该来自分镜，不该让用户手工维护文件名。
