# 导演台简化与计费核查

## 当前结论

本轮已修复单次方案请求结束后仍占用完整授权、授权后取消留下未使用额度、部分费用状态含糊，以及镜头重复应用等问题。已更新 10588 主站、画布共享计费模块与后端。

**不能把本次结果写成“真实付费验收通过”。** 验证没有向真实模型提交请求。只读核查显示，开发库近 7 天没有导演助理的真实授权记录；17 项默认 Agent 配置仍使用 Agnes 测试模型，生产检查不通过。未擅自替换默认模型或改动任何余额。

## 功能与费用边界

| 操作 | 是否调用模型 | 已验证的结果与限制 |
| --- | --- | --- |
| 六个运镜预设、拖路线、播放、人物摆放 | 否，不扣积分 | 本地计算与原生引擎播放 |
| 应用方案、撤销、清空与恢复关键帧 | 否，不扣积分 | 原镜头保留；同一 AI 镜头禁止连点重复添加 |
| AI 设计镜头 | 每次确认后最多调用一次文本模型 | 默认 1 个镜头，仍可选 3 / 6；可应用相机路线，表演与光影等文字建议不等于已经制作 |
| AI 搭场景与调整 | 每次确认后最多调用一次文本模型 | 使用现成白模人物、几何布景、姿势与路线；不是生成任意真实 3D 模型 |
| 微表情、白模精修、衔接等技能 | 文本模型 | 输出制作建议，不承诺白模引擎已经完成微表情、材质或转场 |
| 带入画布 | 本地建立待制作节点，不调用媒体模型 | 图片和视频生成需另行确认费用 |

## 已完成的改动

1. **一次确认对应一个导演方案调用。** 前端显示上限与后端授权写入统一为 1 次；禁止后台自行多轮调用或失败自动重试。
2. **请求结束关闭该次授权。** 成功、输入错误、模型错误和断开连接都进入结束处理。只释放未使用的授权额度；已提交、尚未结算的保守预留仍保留。没有写用户余额、伪造退款或根据余额差推算账单。
3. **取消清理。** 已拿到授权编号但还没提交就取消时，关闭未使用的授权；关闭失败则由服务端到期机制保护，不重发模型。
4. **真实区分费用状态。** 只有后台预算账本已经停止且调用数为 0、也无消费记录时，才显示“未发起模型调用，未产生模型费用”。已提交但无账单时保持待核对，不把网络失败当免费或已退款。
5. **可授权额度一致。** 费用预览扣除其他任务占用的额度，与正式授权时的保守规则一致；并发变化仍由后台事务最终裁决。
6. **减少无效结果。** 原请求输出 5500 / 6500 Token，但网关实际封顶 4096。现在请求、预估上限与网关一致，并要求简短、完整的 JSON；默认先做 1 个镜头。模型不完整或格式无效时不应用、不自动重试，提示已提交用量可能计费。
7. **简化操作。** 本地操作与 AI 生成明确区分，已添加结果集中提供重播、返回编辑和撤销。保留 3 / 6 镜头、全部导演技能和高级参数。
8. **取消提前拦截。** 在取得并发名额和进行预算预留之前检查中止信号，尽量避免用户已退出后继续准备调用。

## 验证依据

- 32 项相关单元测试通过，含请求上限、费用状态、账号边界、成功 / 失败 / 断线结束授权、模型格式与预算规则。
- PostgreSQL 临时事务夹具通过：同一授权不能重复使用，不能跨账号或跨接口使用，令牌有限额与到期时间，结束后拒绝再次调用；真实令牌写入 0、付费请求 0。
- 隔离浏览器计费验证通过：确认前取消、授权后取消、免费改价拦截、未提交状态、未知结果不重试 / 不伪造退款。
- 真实 Vue 与 MONOFORM 引擎的隔离回归通过：完整本地操作不请求费用授权；一次确认生成测试镜头方案，应用 / 撤销不追加模型调用；白模人物、桌椅实际导入与恢复成功。
- 七项已安装技能按代表性需求组装实际请求，均通过当前纯文本预算边界检查；未向模型发送。这不代表所有长度、模型和艺术效果均已验收。
- 前后端类型检查、主站及画布生产构建通过。10588 实际入口、计费资源、3D 脚本、画布入口及健康检查通过。没有启动其他前端服务端口。

## 上线前仍需完成

- 在生产配置中明确选择正式模型，关闭测试渠道并通过生产检查。
- 使用正式账号、正式模型做受控小额验收：成功结果可用，调用次数正确，request_id 能关联消费日志，界面显示积分与网关账单一致。
- 再验证实际取消 / 超时 / 无效输出的结算。模型已接收请求后，即使结果不满意或客户端停止，也可能产生费用；退款须以真实网关记录与平台规则为准，不能用模拟结果代替。
- 批量、大场景与长时间使用应另做性能与恢复验证。本轮不构成 2000 人同时生成或全型号计费验收证明。
