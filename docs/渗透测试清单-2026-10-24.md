## 一、账户隔离 / 越权（最高优先级）

准备：账号 A、账号 B（普通用户）、管理员账号。

- [ ] 画布任务探测：A 创建图片任务，记下 task_id；B 用自己的 token `GET /api/v1/canvas/image-tasks/<A 的 task_id>` → 应 404（代码层 getForUser 已按 user_id 过滤，实测确认）。
- [ ] 画布文件越权：A 上传画布素材得到 `/oss/canvas-files/<A>/<uuid>.png`；B 直接 GET 该 URL → 应 403/404（privateMedia 归属校验）。
- [ ] 画布元数据越权：B `GET /api/canvases/<A 的画布 id>` / `PUT meta` / `DELETE` → 应 404（owner 不匹配不泄露存在性）。
- [ ] 工作区文档越权：B `GET /workspace/documents/viral/<A 的草稿 id>` → 应空/404。
- [ ] 计费越权：B `GET /api/billing/receipt/<A 的 billing_id>`、`POST /api/billing/budget/<A 的 id>/stop` → 应无数据/拒绝。
- [ ] 管理接口越权：普通用户 token 打 `GET /api/admin/tasks`、`POST /api/admin/credits` → 应 403。
- [ ] 网关管理令牌：确认前端产物（`grep -r "NEWAPI_ADMIN_TOKEN" backend/data/web/assets/`）无管理员令牌泄露。
- [ ] resourceScope 回归：A 用 B 的 projectId/scriptId 调 `project/editProject`、`assets/saveAssets`、`production/workbench/batchGenerateVideo` → 应 ScopeError（422/403）。

## 二、支付 / 透支（开收款前必须全过）

- [ ] 预算透支：把用户余额扣到接近 0，提交超过余额的预算授权 → 应被拒（"本轮预算不能超过剩余可授权积分"）。
- [ ] 并发透支：并发 10 个授权请求（脚本同时打 `POST /api/billing/authorize`）→ 通过数 × 上限 ≤ 余额（FOR UPDATE 行锁验证）。
- [ ] 预算重放：同一 billing_id 连续两次 claim → 第二次应失败（"预算已使用"）。
- [ ] 卡密重复兑换：同一卡密在两个会话同时提交 `POST /api/user/topup` → 只有一个成功（网关侧原子性）。
- [ ] 卡密面额与到账：兑换后 `users.quota` 增量 = 卡密面额，`redemptions.status` 变更。
- [ ] 免费模型闸：用零预算调付费模型 → 应拒绝（"当前模型不是可验证的免费模型"）。
- [ ] 空白授权：prod 下不指定模型提交预算 → 应拒绝。
- [ ] 失败退款：制造一次视频任务超时 → 预算释放、额度退回、账单核对一致（防"白嫖"与"双扣"两个方向）。

## 三、SSRF / 文件上传

- [ ] download-output 外链：`GET /api/download-output?url=http://127.0.0.1:3000/api/status` → 应 400"不允许访问内网"；`http://169.254.169.254/`（云元数据）同拒。
- [ ] DNS rebinding：自建域名解析到 127.0.0.1 再代理 → 应被 makeSafeLookup 拦截。
- [ ] 伪装扩展：把 `.html`（含脚本）改名为 `.png` 上传 → 服务端魔数校验应拒绝或按二进制落盘 + CSP sandbox 不可执行。
- [ ] 路径穿越：`GET /api/download-output?url=/oss/../../etc/passwd` → 应 400/404（is-path-inside）。
- [ ] SVG 上传 → 访问时确认响应带 `CSP: sandbox; default-src 'none'` 且不执行脚本。
- [ ] 配额绕过：连续上传超过个人存储配额 → 应 413/拒绝，不落盘。

## 四、XSS

- [ ] AI 回复注入：让模型输出 `<img src=x onerror=alert(1)>` → 主站渲染应转义为文本。
- [ ] 画布节点文本：节点标题/文本输入 `<script>` → atelier 渲染为纯文本。
- [ ] 画布标题/草稿标题注入 `<script>` → 列表页（Vue/React 两端）都应转义。
- [ ] 导出 CSV 公式注入：提示词里带 `=HYPERLINK(...)` 导出 → 文件以 `'` 前缀转义（usageCsvCell）或接受风险说明。

## 五、滥用 / DOS

- [ ] 生成限流：脚本 1 分钟内打满 generationLimiter → 后续请求被限流响应。
- [ ] download-output 代理限流：30 次/min/用户，超限被拒。
- [ ] 全局限流：1200 req/min/用户。
- [ ] 上传大小：>128MB 素材 → 明确报错；base64 大于单文件上限 → 413。
- [ ] 预算堆积：连续确认 21 个预算 → 第 21 个被拒（"未使用的预算确认过多"）。
