# 智能画布创作入口与技能

首页保留用户在 2026-10-08 调整后的 UI：紧凑轮播、输入框上方的创作分类、浅色选中态、模型费用区域、素材与媒体设置。恢复依据是接入分析助手前保存的工作区快照，而非更早的 Git 版本。发送创意时携带草稿、技能、模型、媒体设置与附件进入 `/canvas?source=xoi&handoff=1`，由原画布 Agent 执行。首页不再承载新增的分析聊天框，也没有「画布创作 / 分析助手」切换。

画布原对话、会话历史、节点工具、媒体生成与权限逻辑保留。新增能力作为原输入框中的两个浮层：

- **技能**：搜索、全部、导演与分镜、通用创作、我的、已选；列表可直接勾选，选择后保持浮层打开，最多搭配五项。底部与入口显示已选状态，可立即移除。搜索跨分类并支持需求词；详情说明准备材料与产出，「填入示例需求」追加到已有草稿，仍由用户发送。选择在当前对话持续可见，移除全部后不会偷偷沿用上一轮技能；打开历史对话恢复该对话已使用的技能。已接入的七项导演技能使用中文名称；只展示 `SKILL.md` 入口，不把后台路由、README 和辅助文档当成技能；已安装市场技能的 `community/*.md` 入口继续保留，辅助文档通过原 Agent 的 `read_skill_file` 工具按需读取。
- **拆解参考视频**：使用对话已引用的视频或临时上传的视频，描述拆解目标后开始分析。先在浏览器抽取 12 帧，再提交给参考分析端点；显示时间戳、结果、错误与停止按钮。只有完整完成后才能「填入对话」，追加到现有草稿，由用户继续发送给原画布 Agent。填入结果本身不会调用生成或写入节点。

参考分析端点仅有视觉分析权限，不能调用媒体生成或修改画布。视频帧不包含音轨。普通画布发送与 Agent 工具循环不受参考浮层影响；关闭浮层、停止或账号切换会取消未完成分析。

技能服务统一走经过宿主身份校验的 XOi 接口，兼容返回 `code: 200`，上游画布直接复用该服务。「我的技能」导入、编辑、删除保存到按账号分库的 IndexedDB；系统购买文件继续由后端读取，不把付费正文提交到 Git，也不把未接入的其余技能标为可用。

## 验证

- `frontend/scripts/test-assistant-workspaces.mjs`：真实 Vue 组件，验证恢复轮播与分类、原创作发送携带技能 / 模型 / 图片进入画布，首页没有分析请求。
- `frontend/scripts/test-canvas-reference-tools.mjs`：真实 React / Ant Design 浮层与浏览器视频解码，验证七个技能入口、内部文档过滤、连续多选、数量限制、移除、跨分类搜索、示例保留草稿、键盘关闭与手机浮层边界、12 帧、保留已有草稿、不会自动生成、失败 / 停止与账号分库。
- 测试使用模拟模型响应，不调用付费模型；真实模型需支持视觉与工具调用。

## 技能选择原则

技能是原画布 Agent 的可选创作方法，普通对话不要求先选技能。输入框中的标签就是当前对话实际使用的技能，收起再打开也保持一致；新建对话清空，历史对话恢复自己的选择。组合上限沿用画布的五项限制，日常建议先选择一至两项，避免多个完整工作流争夺输出格式。

故事拆镜优先用「导演分镜表」，构图与光影用「电影镜头设计」，人物情绪可搭配「情绪与场面调度」和「微表情指导」。已有预演用「白模预演精修」，空间飞行用「FPV 穿越运镜」，多素材衔接用「镜头衔接与转场」。示例需求默认先给方案，生成操作仍遵循原 Agent 的模型、工具与自动生成设置。

购买目录核对为 175 个 `SKILL.md`，没有 `.mp4`、`.webm` 或 `.mov` 示例视频文件。画布目前使用已部署的七项导演入口与原有通用、已安装市场技能；其余购买技能需逐项核对专用工具、附属文件和输出要求，不能仅凭存在 `SKILL.md` 就标成已经接通。原厂工具名、指定视频模型、文件导出路径也不能自动赋予 XOi 新能力。
