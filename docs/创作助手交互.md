# 创作助手：一个对话入口

创作首页以用户的任务为中心：说想法、上传参考、选创作技能，都在同一个输入区。首页不再展示“画布创作 / 分析助手”两种后台角色，也不要求用户先理解工具权限。

## 使用流程

1. 输入想法，或上传图片 / 一段视频。仅有参考、没有文字时也能发送。
2. 发送后自动准备图片或抽取 12 张视频参考画面，在回复中显示进度。视频观察基于抽样画面，不读取音轨。
3. 在同一段对话继续修改故事、创意、镜头和提示词。顶部历史可以切换对话；刷新页面、从画布返回时恢复当前文字对话。未发送的文字草稿按账号保存，原始文件和抽样预览仅保留在当前页面内存中。
4. 准备制作时，点击回复下方的“在画布制作”。只传递被选中的方案和已选技能 / 模型偏好，不混入其他未发送的草稿附件。画布沿用既有制作流程。
5. 顶部“画布 / 导演台”是具体工作页面的导航，不会因切换页面自行发起模型请求。

## 控件层级

首页保持一个对话模型入口。模型报价仍可在选择器中查看，“用量”按需展示当前对话的估计费用与计费说明；不把图片尺寸、视频画质和生成模型堆进尚未确定方案的输入区。

空态只提供三个创作起点：拆解参考、打磨分镜、策划短片。历史与新对话固定在顶部，发送和停止固定在输入区。

## 执行权限

前台统一交互，后台继续按操作限制权限：本页开放参考视觉分析与文字创作，不开放媒体生成或画布读写。图片必须在客户端缩放并由服务端解码校验；视频工具只允许一次有界分析循环。技能仅提供工作流指引，不能授予新工具权限。

图片参考需要所选模型支持视觉输入；视频参考需要同时支持工具调用和视觉输入。不支持时明确报错并保留参考供重试。切换账号会取消请求、清除当前可见参考，旧请求不会进入新账号对话。

## 验证

`frontend/scripts/test-assistant-workspaces.mjs` 编译真实 Vue 页面并使用浏览器解码视频，模型接口使用测试响应，验证单一输入区、自动抽帧、图片处理、连续对话、恢复历史、停止 / 失败重试、显式方案交接和账号隔离。后端 `videoAnalysis.test.ts` 验证输入解码、权限边界、工具循环与流式异常。测试不消耗真实模型积分。
