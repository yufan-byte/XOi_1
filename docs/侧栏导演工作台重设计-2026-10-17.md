# 侧栏重设计：宽松布局与可发现的展开按钮

本轮是对上一版“按钮放在账号旁、导航过紧”的修订，只改前端侧栏及其 UI 偏好，不修改模型、渠道、积分或服务端任务。

## 布局原则

- 展开宽度 272px，导航行高 52px、行间距 7px、图标与标题间距 15px；余额字号 20px。不要把所有内容压小来适应窗口。
- 按钮改为品牌分隔线下方、侧栏右边界上的独立箭头，30×34px。它是滚动容器外的原生按钮，收起时随侧栏边界移动，保留可见的展开入口。
- “更多工具”独立固定在账号区上方；较矮窗口只滚动中间的主导航，不挤压工具入口、余额和账号。
- 桌面默认展开，业务导航不再自动收起。保留用户明确选择的展开/收起状态；旧的自动收起标志不再决定桌面宽度。手机仍默认图标栏，可手动展开。
- 轻量导演元素：品牌区场记条与 DIRECTOR’S DESK 副标、创作/资源分区编号、细分隔线、暖白与橙色当前状态。没有额外堆叠大图或装饰卡片。

## 检查范围

- 偏好测试覆盖默认展开、旧自动标志迁移、手动收起/展开保留、无效偏好恢复。
- 隔离 UI 测试检查按钮的实际命中区域，真实鼠标点击折叠往返，并等待按钮与侧栏边缘对齐后再截图。
- 检查 620px 高度下导航独立滚动、按钮与固定工具入口不被裁切；390px 宽度下无横向溢出。
- 复用原有模型与复刻页回归用例，防止侧栏改变误触模型调用或草稿写入。隔离测试服务器不代理真实后端。

构建产物发布顺序：先更新资源、再切换 HTML，保留旧哈希资源；独立控制台和画布产物不覆盖，后端不重启。
