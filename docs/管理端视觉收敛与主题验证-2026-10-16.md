# 管理端视觉收敛与主题验证（2026-10-16）

## 范围

只调整 XOi `/console/reseller/*` 管理界面的样式与主题交互。不改 NewAPI 账号、渠道、价格、用户积分、支付接口或生成逻辑。保留登录页原有舞台设计及用户已有的主题选择。

## 调整

- 管理端独立使用暖白、浅灰与少量橙色；深色模式使用中性炭灰，不再大面积染紫。
- 配色作用于管理路由的 html，弹出菜单和对话框一起继承；离开管理路由后移除。
- 侧栏去渐变、发光与彩色虚线框，选中项使用浅底与细强调线；侧栏内容可滚动。
- 顶栏减少与侧栏重复的入口，保留位置标题、搜索、主题、公告与用户菜单。
- 收简页头与指标卡，统一留白、细边框、表格悬停和键盘焦点；日期筛选放到概览标题旁。
- 协议入口移至概览底部，不再悬浮遮挡内容。
- 多个主题控件共享状态，响应系统主题、跨窗口存储变化；存储写入受限时，本页面仍可临时切换主题。通知提示跟随当前主题，不必刷新。
- 修正 Tailwind v4 裸 `border` 使用 currentColor 造成的过重描边，保留明确声明的错误、成功等语义边框。

## 验证方法

运行 `frontend/scripts/preview-console-appearance.mjs` 启动仅绑定随机 loopback 端口的视觉夹具服务。该服务不连接 XOi/NewAPI，上游数据均为内置模拟数据，所有非 GET 请求拒绝。测试用登录标记没有真实签名，不能用于生产认证。

使用 `web-access` 的 CDP Proxy 执行：

```sh
cd frontend/console
npm run typecheck
npm run build
cd ../..
node frontend/scripts/test-console-appearance.mjs
node ops/check-console-assets.mjs
```

浏览器回归覆盖：浅/深色配色、刷新保留主题、body 下弹出菜单继承主题、模型定价表、折叠导航分组展开、390px iframe 窄屏抽屉与自动收起、系统主题、离开管理页后的登录配色隔离。桌面与窄屏均检查无页面横向溢出。窄屏验证是浏览器 iframe 布局测试，不等于真机验收。

最终实测：类型检查、生产构建、全部 9 项浏览器回归与 3 项静态资源门禁通过；收费请求 0、API 写操作 0。截图保存在 `docs/验证/管理端视觉-2026-10-16/`，其中金额、客户及模型数据均为模拟展示，不是实际运营数据。

## 本地生效与限制

构建产物同步目标为 `backend/data/web/console`：先同步资源，最后更新入口 HTML，保留旧哈希资源。无需修改或重启后端代码。

检查初期 `localhost:10588` 未监听，最终复核时服务已在运行。本次没有启动或重启业务后端。HTTP 验证管理页 HTML 与新构建逐字一致，入口 JS 与 CSS 均返回 200；实际浏览器确认 `/console/reseller/overview` 已渲染新管理壳与 `--primary: #b94b18`。真实业务数据的增删改、充值和生成没有测试，不能据此视为整个平台生产验收。原有构建的字体解析与大块文件提示不在本次管理端配色范围内。

## 补充：团队独立路由主题遗漏

用户反馈点击团队管理后颜色仍不一致。确认 `/console/team` 是独立路由，前次只有 `/console/reseller/*` 挂载了管理配色；团队页同时沿用旧的默认深色判断。实际页面有内容且没有团队加载错误，但没有 `xoi-management` 作用域，仍使用紫色主题变量。

改为由共同的 `ManagementAppearance` 路由布局管理配色和加载底色，团队默认主题同样设为浅色，保留显式的深色或系统偏好。这个布局只负责外观，不包含 AdminGate；普通团队成员仍可访问自己的团队页，不会因此获得后台权限。管理员团队页补充返回管理控制台的入口。

扩展回归至 16 项：包含管理页进入团队、团队返回管理页、所有者概览/成员/消费明细、添加成员弹窗配色（只打开不提交）、普通成员无后台权限、未开通团队的直接入口、390px 团队布局。全部通过，API 写操作和收费请求均为 0；类型检查、构建及资源门禁通过。模拟截图 `team-owner.png`、`team-member-dialog.png` 保存在前述验证目录。

新版已同步到 10588 实际静态目录，HTTP 校验团队页入口与最新构建一致。实际浏览器复核 `/console/team`：管理配色作用域存在，主色 `#b94b18`，背景 `rgb(247, 247, 245)`，团队页面正常渲染且无加载错误。未改团队接口、成员权限、额度与扣费逻辑；没有创建真实成员或划拨额度。
