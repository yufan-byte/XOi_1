# 导演工作区布局修复与验证

日期：2026-10-12

## 本次修改

- 项目页移除误露出的装饰圆环；新建项目仍放在右侧，项目入口和操作保留。
- 流程提示保留在工作区左下角，默认显示小胶囊，点击可展开或收起。最大宽度 560px，窄屏随工作区收缩。收放状态在当前浏览器会话内保留。提示有独立的布局位置，不压住侧栏、聊天输入框或操作区；没有流程提示的页面不保留空白区域。
- 剧本创作助手将聊天记录限制在自身区域内滚动，输入框、模型选择、价格提示和连接状态不再与聊天记录争用高度。高度不足时允许工作区滚动；窄屏改为上下布局。
- 剧本整理的搜索及操作按钮可换行，剧本卡片限制在工作区宽度内，步骤提示保留原有前置校验。
- 制作画布保留七个节点和六条连接；整理画布后采用两行布局。长剧本、资产和分镜列表在节点内部滚动，避免单个节点过高挤小总览。节点使用编号、深色场记板标题和简洁说明，编辑、生成和剪辑入口保留。
- 总览、自动排版和阶段定位预留顶部工具栏的空间；首次进入制作画布定位当前任务，用户点击阶段入口时才打开对应工作区。
- 将剧本整理页面的全局样式限定到页面根元素，避免同名“script”样式影响制作画布中的剧本节点。

## 验证方法与范围

使用独立的无头浏览器和固定的接口数据，验证布局及导航，不使用用户登录会话。模拟五条长对话、55 段剧本和八个资产；拦截 API 与实时连接，未保存项目、未提交生成任务、未产生模型费用。

已通过开发页面的检查：

- 项目页装饰圆环不存在，新建项目按钮保留。
- 1440×900、1440×720、390×844 下，聊天内容独立滚动，输入框可点击、可输入空格，模型及费用区域位于助手面板内。
- 步骤提示收起后宽度小于 320px，展开后宽度不超过 560px，位置属于工作区，不覆盖侧栏；可正常收放。
- 七个制作节点互不重叠，六条连接保留，长剧本及资产可滚动，节点避开顶部工具栏。
- 剧本节点的原有编辑对话框可以打开并取消。
- 直接打开剧本整理页面也能显示流程提示；展开后可从剧本整理进入角色场景，再进入分镜成片，项目 ID 保留。流程页面只有一个提示卡片，制作画布没有多余底部占位。
- 页面没有未捕获异常，没有生成或保存请求。

类型检查、生产构建和差异格式检查已通过。构建产物已同步到 10588；在该端口再次执行上述布局和跨页导航检查，全部通过。生产构建仍有仓库现有的 Sass 弃用及大包提示。

此验证确认布局与导航行为，不代替真实 AI 任务、团队协作或并发性能测试。
