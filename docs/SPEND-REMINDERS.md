# 消费提醒与普通生成（按用户最新要求，取代早期逐任务预算确认）

- 普通模型生成使用 `automatic=true` 的后台调用记录：点击生成即执行，不弹逐次费用确认，不再用猜测的累计预留金额阻断正常批量。模型实际消耗仍由当前用户的 NewAPI 钱包和日志结算，浏览器不接触上游密钥。
- `freeOnly` 的 Agnes 测试每次执行前仍核对真实零价，不因测试失败切到收费模型。账号鉴权、模型访问范围、幂等、取消和任务租约不变。
- `xoi_billing_preferences` 按账号保存今日提醒金额（元），默认20元，0关闭。不是日消费上限，不参与生成准入。北京时间自然日，累计当日正向模型扣款，退款单独记录；1元=10积分。
- `xoi_daily_spend_notices` 通过账号/日期/提醒金额唯一键去重。达到后同日同一设置只提醒一次，提醒可关闭、15秒后消失，不调用停止任务接口。设置提高后可在达到新金额时再次提醒；所有设备共享设置与去重状态。
- 普通提交、免费账单、正常扣款、预算状态变化不再生成右下角常驻费用浮窗；保留页内任务状态及积分明细。提醒服务异常也不使生成失败。
- 自动任务保留仅针对明显异常的兜底：单轮1000次调用、2小时有效期、可可靠估算的单次超过1万元等；没有把它们宣传成真实钱包硬封顶。普通请求不生成二级预算令牌，不以预留额度假充实际扣费。
- 显式旧预算模式仍兼容旧客户端及已确认任务，不能把它的保守预留压低来冒充安全硬限。失败并不自动退款；只显示可核验的上游账单。

## 验证

`backend/scripts/test-daily-spend-pg.ts` 在随机本地 schema 中测试北京时间边界、账号隔离、真实消费过滤、16并发只提醒一次、跨连接保存、关闭提醒和新一天归零。不会伪造真实用户消费。

`frontend/scripts/test-daily-spend-ux.mjs` 使用仅本机模拟接口验证连续5次不弹确认、不出现逐次费用浮窗、达到日金额仅提醒、不调用取消接口。

`backend/scripts/test-automatic-free-batch.ts` 是显式开启的本地 Agnes 零价真实测试：一轮授权并发5次、实际调用数5、无累计预留、账单0积分。未开启时不运行，也不测试收费型号。以实际运行结果为准。

收费型号未逐个实测，2000人容量未认证；不能由HTTP200或目录可见推导所有上游生成都成功。已知免费Agnes文字与图片已成功；视频最近一次返回上游队列已满，不能宣称成功出片。
