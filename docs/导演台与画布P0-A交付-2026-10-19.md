# 导演台与画布 P0-A：单镜头场景交接

日期：2026-10-19。对应 [整体 PRD](./导演台与画布一体化预演制作PRD-2026-10-18.md) 中的第一阶段。

## 本次可用的流程

1. 在导演台摆放人物、布景和主摄影机，选择当前镜头。
2. 点击「带到画布制作」。先确认云端保存，再上传真实机位截图，最后进入画布；不会自动生成媒体。
3. 画布得到四个有连线的节点：可继续编辑的导演节点、当前帧图片、镜头说明、视频配置。时长和画幅继承当前镜头。
4. 点击「继续编辑这个镜头」，打开同一场景、同一镜头，修改后「保存并返回」。
5. 旧图片、旧参考版本及已有生成结果保留；再次带入产生新参考，不冒充旧版本的画面。
6. 当原场景已有更新，先选择打开最新场景或将旧参考另存为新场景；不静默覆盖。
7. 画布内运镜入口说明需要完整导演台，点击后保存并继续同一个场景，避免无响应按钮。画布只在打开编辑时加载 3D 引擎，节点封面不常驻 WebGL。

## 保存与恢复

- 场景目录和原生工程通过 `/api/director-scenes` 保存到现有 PostgreSQL 工作区文档表，账号隔离，版本比较后保存。
- 保留本机草稿。完成编辑后保存草稿，播放期间不因自动保存暂停预演；后台定期补保存。
- 保存失败留在编辑器，可重试，或明确保留本机草稿并返回。
- 版本冲突不覆盖云端，保留本机副本，允许下载后处理；使用云端版本前保存本机备份。
- 明确删除按版本核对并保留删除标记；旧客户端不能把已删除场景重新覆盖回来。
- 已导出的画布节点携带不可变工程快照与 `sceneId / shotId / revision / frame`，原场景不可用时可另存参考副本。
- 只使用原生保存按钮和可移植工程存储，不依赖引擎内部 React 对象或修改压缩引擎。

## 费用边界

本次新增的保存、恢复、截图、带入、编辑和另存均不调用模型，不产生模型扣费。视频配置节点保留现有模型选择与费用确认流程，点击「带到画布制作」不会自动点击生成。

本轮浏览器验证使用隔离账号、模拟场景与账单接口，没有操作真实用户场景或发起真实模型请求；这不等于重新验收所有模型的供应商可用性。
