# 3D 导演台：按钮遮挡、运镜播放与清空

本轮根据实际使用反馈修复三个问题，保留现有场景、镜头和制作功能。

## 调整

- 头部按 AI 助理按钮的实际宽度预留位置，不再使用固定宽度。空间不足时分成两行；窄屏打开助理后也保留导出按钮的可见区域。
- 运镜面板上方直接显示镜头主体和“应用并播放运镜”，与路线草稿区分。操作区在滚动时保持可见。
- 应用运镜后自动切到主摄像机画面，从开头播放，并提供暂停、继续、从头重播、返回场景编辑。小摄像机预览在这时收起，返回编辑时恢复。
- 手动记录了至少两个镜头关键帧后，从编辑视角点击播放或按空格也会进入主摄像机预演。
- 镜头轨道、当前人物或物体轨道各自有“清空”。清空使用原生轨道删除回调，不通过名称识别对象，不删除人物或其他轨道。
- 清空后提供“撤销清空”。先校验前后工程只清空了一条轨道，再保存撤销版本；工程继续被修改时不使用旧备份覆盖。

## 验证

前端类型检查、生产构建通过，十项底层验证通过。

隔离浏览器使用原生 3D 编辑器和测试 API 响应，验证：

1. 1440、1180、1000 像素窗口下，导出工程、截图、导出 MP4 与助理按钮不重叠。
2. 清空人物记录保留镜头记录与对象，撤销恢复全部人物记录；预览后也能撤销清空。
3. 清空镜头记录保留人物动画，撤销恢复全部镜头记录。
4. 路线草稿不会立即改工程；应用后进入主摄像机画面，帧数推进，实际镜头包含不同位置的关键帧。
5. 暂停、重播、返回编辑、收放小摄像机预览正常。
6. 播放时清空能先暂停，61 个采样点的路径可以完整恢复。
7. 助理打开时的窄屏头部不遮挡导出，应用按钮不需要滚到面板底部寻找。
8. 没有页面异常、实际后台写入或付费模型调用。
