# 创作流程流畅度优化 · 2026-10-11

本轮针对反复进入画布的等待、右侧新建项目按钮，以及项目到素材、剧本、制作流程的交互等待。保留原有创作、模型、积分、技能、编辑和导入功能。

## 改动

- 新建项目恢复右侧。右侧区域使用正常文档流：装饰在上，按钮在下，留出独立间隔。窄屏保留右对齐按钮，装饰收起。
- 画布首次进入才启动。离开时保留同一个 iframe 在 DOM 中，返回恢复原工作区；不会重新验证账号、读取模型、读取画布工程。切换账号或退出会丢弃旧工作区。显式新建、导图、复刻、提示词交接仍走原有入口。
- 离开画布暂停原本正在播放的媒体，返回后恢复；保留生成和保存操作。
- 菜单意图触发代码预加载；下一步在允许前往时提前加载页面代码，节流网络模式关闭预加载。预加载不请求项目数据、不发起模型调用。
- 路由切换显示即时进度；项目打开和下一步按钮等待到导航完成，防止重复点击。
- 空剧本助手不提前加载 Markdown 编辑器；文档解析库仅在读取 DOCX 时加载。剧本添加、批量导入、编辑弹窗首次使用才加载，打开后保留原来的草稿行为。
- 制作页面按项目复用，切换分集读取对应内容；分集与聊天历史并行请求，切换期间选择器显示等待状态，保留生成中的切换确认。
- 画布冷启动把 React 等无账号依赖的模块下载与身份核验并行；涉及账号存储的模块仍在身份验证完成后加载。主题桥接独立加载，避免首页为同步主题提前下载图像上传及旧画布编辑模块。
- 工作台大面积装饰背景保持静态，减少滚动与输入时的持续绘制负担。

## 验证与边界

测试使用隔离浏览器和拦截 API 的固定数据，不调用付费模型，也不写入用户项目。覆盖桌面 1440、窄屏 1000、手机 390 像素：项目按钮无重叠、页面无横向溢出，项目弹窗、素材导入、剧本助手输入伸缩、技能选择和设置入口均可操作。

画布往返检查使用 iframe 的时间原点和窗口标记，确认浏览器上下文未重建，返回没有新增认证或模型请求；另检查显式新建仍执行、Markdown 编辑器能加载现有文本。

在改动前的实际登录浏览器中观察到一次模型配置请求约 3.5 秒，用户配置/画布列表各约 0.7 秒。这些接口和上游模型生成仍有实际响应时间；本轮主要消除重复启动、无关模块下载和串行等待，不能把本机测试时长当作服务器 2000 并发的性能承诺。

最终验证：Vue 类型检查通过，主站与 Atelier 生产构建通过，静态产物已同步至 `http://localhost:10588/`。在该生产端口的隔离测试中，1440 / 1000 / 390 像素布局与操作检查通过；画布原上下文复用、新建入口、现有 Markdown 草稿编辑通过；制作页分集 URL 切换保留原 DOM，分集内容与历史各请求一次，两个请求并行发出，均无未捕获页面异常。

另外在实际登录浏览器中进行只读往返导航：返回画布约 15 毫秒，iframe 及运行时未重建，新增画布接口请求数为 0。此数值仅代表本机已加载工作区的返回速度。右侧按钮实景截图见 `验证/2026-10-11流畅度优化/项目页-右侧新建.png`。
