## 价格与积分的最终呈现

模型卡：产品名称、一个简短用途标签、明确计费单位，480p/720p 单价同时展示；价格不抢占整行主视觉。

生成区：根据当前清晰度、时长、数量和参考素材更新总价。例如无加价时，即梦 2.0 的 720p、5 秒、无参考视频为 37.5 积分（¥3.75）；带参考视频为 56.25 积分（¥5.625）。

本站售价 = 上游实际计费组价格 × 本站加价倍率；积分 = 本站售价 × 10。若假设加价 30%，前例分别为 48.75 积分和 73.125 积分。该 30% 仅为说明，不表示已应用。预览舍入不应改变网关结算精度。

选择页展示“默认规格参考价”，生成页展示“本次预计”；分档、按实际成本和 token 计费的任务不可冒充固定最终报价。批量生成应展示整批预计消耗，费用变化前置提示。

## 文字价格与失败恢复修正（2026-10-11）

- 根因之一是同步规则：Token 模型的 `model_price: 0` 是占位字段；将其写入 NewAPI `ModelPrice` 会把模型切换成按次零价。此前“目录有价格、unquoted 为空”的检查不足以发现这个问题。本次删除这类错误条目，保留真实免费按次模型、输入倍率、输出倍率及缓存倍率。
