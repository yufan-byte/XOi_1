# 一站式作品生产与验收

## 使用

主站「剧本创作 → 快速创作」，保存故事，在项目设置选择文字、图片、视频模型，再点「后台连续制作」。

- **AI 视频**：设定/意图 → 剧本 → 资产 → 定妆图 → 分镜图 → AI 逐镜视频 →（可选台词配音）→ 服务器合成 MP4。模型费用按实际用量计入本账号；每日提醒不停止任务。
- **图片运镜**：须在项目设置主动选择。使用生成的分镜图做缓慢推进镜头，再合成 MP4；这不是 AI 视频生成，不调用视频模型。文案/图片/可选语音仍按所选模型计费。本地运镜和合成不扣模型积分。不会因视频上游忙而偷偷切换模式或收费型号。
- **尾帧续接**：AI 视频且线路支持首帧才可选择。每集首镜用自己的关键帧，其余镜头从本集上一镜末帧接起。不跨集接镜。重生前镜会把后续镜头标为待重生。
- 「成片」页可合成/下载 MP4，合成成功自动归档到服务器、记录项目版本并标为完成；刷新或换设备读取同一项目可继续下载。修改镜头/配音后，旧成片保留但会提示重新合成。
- 本机 WebM 仅为备用导出，不自动同步。
- 可显式选择「纯提示词」视频输入：不发送关键帧/角色图，连续制作不自动生成图片，不需要公网参考图；不支持尾帧续接，跨镜头外貌一致性弱于参考图模式。默认仍是参考图模式，不会因上传失败自动降级。

## 服务依赖

1. FFmpeg 与 FFprobe（需 libx264 / AAC）。生产根 Dockerfile 已安装；裸机 `apt-get install ffmpeg`，或配置 `XOI_FFMPEG_PATH`、`XOI_FFPROBE_PATH`。缺失依赖会提示安装，不重新生成模型镜头。
2. PostgreSQL、NewAPI 及既有共享 OSS 目录。多节点必须访问同一素材存储；不把用户素材放在临时发布目录。
3. Seedance URL-only 线路要配置 `XOI_PUBLIC_BASE_URL=https://网站域名`，上游能访问本站归档图片。只用 localhost 的免费 Agnes 测试不需要该配置。不要用客户端传入的域名拼素材链接。
4. 合成使用本站当前账号的归档文件；禁止 HTTP 输入、任意路径、跨账号路径、软链接逃逸和播放列表 demux。编码单节点串行、两线程，临时文件自动清理，成片完整写入后原子发布。

## 持久化与不重复扣费

- 每集剧本、每8镜分镜提示词分批生成，完成一批就保存；小说用 SSE 读取真实流式内容，只有完整 stop 才替换旧章节，中断保留旧内容。
- 文档版本 CAS、执行租约、阶段历史、下一步游标在同一事务中提交。只有成功提交的步骤边界才允许进程重启后安全续跑。
- 已尝试提交而结果不明确的请求仍为待核对，不能仅因过了10分钟就当作失败放行重发。有上游视频编号可查询原任务，未完成不会盲目重新创建。
- 一站式不再用统一20分钟执行期限；每轮有持久化的12小时期限与1000次调用保护。仍开放的自动授权在成功保存的步骤间续租，用户主动停止的授权不续租。其他独立媒体任务仍保留原20分钟限制。
- 单次合成最多200镜、2小时总片长、1GB产物，单源文件最多256MB、单镜/配音最长120秒。超过限制应拆集处理，不删除用户内容。
- 无模型处理任务授权模型列表为空（拒绝任何模型调用），回执明确 `not_billable`，不是“费用待核对”。

### 实测发现并修复

1. 上游专线在模型目录可见，但本地`zaowu-video`插件漏登记三个`-xoi`型号。仅增加这三个模型、发布1.0.3，保留1.0.2；所有原有96个模型与hook不变。
2. 专用视频渠道5被配置成普通OpenAI类型、没有插件绑定。经官方API改为Task Plugin类型61并绑定`zaowu-video`；Key、地址、模型列表、启停不变。原有abilities允许admin/default/xoi，修正渠道group为同一集合，未扩大实际访问范围。
3. 两次前置失败均发生在本地解析/分发阶段，没有取得上游任务号、造物专用Key已用额度仍为0。人工核对后仅结束本次自建验收项目的待核对记录；没有批量处理其他未知任务。
4. 新增显式纯提示词模式，修复批量视频原先只挑选有关键帧镜头的问题；默认参考图行为不变。
5. 修复非自动、有限授权的请求计数/价格快照没有递增的问题。普通自动生成、每日消费提醒逻辑不变，不恢复逐次预算弹窗。

### 仍需区分的验收边界

- 本次证明Fast专线文字生视频→轮询→账单→归档→合成链路成功，不等于全部模型/渠道均已逐一验证。
- 未验证公网图片参考、真人定妆锁定或参考视频1.5倍计费。本地未配置公网素材域名；生产参考图模式仍须按依赖节配置。
- 纯提示词三镜可保持大致服装和场景氛围，但演员细节与表情可能漂移；正式连戏作品优先用角色/构图参考，不应把本次低成本样片说成剧集级人物一致性验收。
- 默认全量渠道6仍为普通OpenAI类型，未在本轮扩大改动；其视频插件绑定应在后续单独修正验证，不能凭目录显示宣称全量视频可用。
