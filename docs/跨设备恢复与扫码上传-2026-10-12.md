# XOi 跨设备恢复与手机传图：本轮实现与上线边界

## 检查结论

换电脑不会自动带走 localStorage / IndexedDB。账号分桶只能防止串号，不能代替云端保存。

| 功能 | 当前数据位置 | 换设备的边界 |
| --- | --- | --- |
| 项目、小说、剧本、分镜、项目素材记录 | PostgreSQL + 后端媒体目录 | 同账号可读；数据库和媒体都必须备份 |
| 新版无限画布项目 | 后端 `data/canvases`，浏览器缓存 | 已有服务端同步；目前文件存储，不宜直接多副本部署；不要删除数据卷 |
| 爆款复刻分镜、阶段、模型规格、任务编号 | 本轮新增 PostgreSQL 文档，IndexedDB 兜底 | 保存成功后可跨设备；离线修改不冒充云端已保存 |
| 复刻上传的视频、商品图 | `data/oss/canvas-files/<用户>`；云端草稿保存地址 | 首次上传一次；跨设备不在打开页面时下载整段源视频 |
| 剪辑时间线 | 本轮新增 PostgreSQL 文档，本机缓存 | 云端媒体可恢复；`blob:` 本机导入素材不能冒充可移植素材 |
| 画布图片/视频生成任务 | 本轮新增 PostgreSQL 任务记录 | 完成结果可恢复；NewAPI 视频保存上游编号后可继续查询原任务 |
| 智能创作助手历史 | 浏览器 localStorage，轻量历史有裁剪 | 本轮未迁移，仍不能保证跨设备完整恢复 |
| 导演 3D 工程、场景和自定义姿势 | 浏览器工程存储 | 本轮未迁移，换设备仍存在缺失风险 |
| 登录凭据、主题、面板状态、短暂页面交接 | 浏览器 | 登录/偏好可以留本机；临时交接不是持久化项目 |

## 本轮实现

- 新增 `xoi_workspace_documents`、`xoi_generation_tasks`、`xoi_upload_sessions`，随后端启动幂等建表，不改已有业务表内容。
- 草稿所有读写以登录身份为准，忽略客户端声明的 owner；版本号条件更新阻止设备之间静默覆盖。
- 复刻先保留本机修改，再保存云端；保存失败阻止该工作流继续提交收费生成。冲突后重新打开原稿时，将本机修改保留为独立副本，再读取云端版本。
- 旧的账号内复刻 IndexedDB 草稿仍保留；打开并成功保存后逐份进入云端，不批量上传用户所有历史素材。
- 剪辑缓存改为账号分桶；可验证归属的旧复刻时间线允许恢复，不自动认领旧的公共本机剪辑草稿。未同步冲突稿保留本机备份，可查看/导出，不覆盖云端。
- 任务提交确认前必须有数据库记录；NewAPI 视频拿到远端编号后，先提交该编号再进入轮询。重启恢复只 GET 原任务与原成片，没有再次 POST 生成的代码路径。
- 同步图片断线、未知视频提交结果不会直接视为“可安全重试”；明确提示结果待核实。没有远端编号的任务不能自动补救。
- 上线前创建的旧内存任务没有历史数据库记录，不能凭空恢复；已有落盘媒体文件不因本轮改动删除。

## 手机扫码上传

造物本地源码 `src/components/media/drawers.tsx` 的扫码功能是当前页面二维码、手机登录同账号后上传。本轮在此基础上增加电脑/手机配对窗口与结果回传。

入口：爆款复刻 → 手机扫码传商品图。手机扫码 → 登录电脑端同一账号 → 选择图片 → 电脑显示图片 → 选择一张用作商品图。

- 二维码只有随机上传窗口编号，不包含 JWT、上游密码或 API Key。
- 手机仍需同账号登录；不同账号不能查询、追加或关闭该窗口。
- 10 分钟有效，每窗口最多 10 张，每张不超过 10MB；支持 PNG/JPG/WebP/GIF，不支持 HEIC/SVG/HTML。
- 服务器只允许关联此账号真实上传目录中的图片，检查文件存在和大小；上传正文复用既有媒体签名校验。
- 电脑仅在窗口打开且页面可见时查询；关闭后停止查询。过期/关闭窗口后不再接受关联，已落盘的图片文件不会随窗口删除。
- 本轮只把“选用的商品图”加入复刻草稿，不代表已完成全站通用云端素材库或画布扫码入口。
- 本机 localhost 二维码不能在另一台手机直接使用。生产环境同域 HTTPS 默认可用；本地联调可在前端构建时配置 `VITE_XOI_PUBLIC_ORIGIN` 为手机可访问的站点地址，并保证 API/登录可达。

## 速度与可靠性

- 上传与草稿 JSON 分离，素材上传在同一页面中去重，后续自动保存只保存引用；视频恢复只取原任务，不重建。
- 草稿列表使用用户/类型/更新时间索引，分页每次 50 条，不一次拉取所有草稿正文；当前复刻侧栏展示最近列表及本机草稿。
- 云端读写超时 15 秒，不沿用普通 AI 请求的十分钟超时；剪辑保存 600ms 去抖，慢网络下合并过时的排队快照，离开页面至多等待 1 秒并先保存本机快照。
- 剪辑缩略图、波形等可再生成的预览缓存不进入云端正文。
- 本机缓存写满时不阻止继续尝试云端保存；若云端与本机均未保存成功，明确提示不要关闭页面，不假称修改已保留。
- 生成流水线结束后清理当前进程的落盘仲裁标记，历史任务只保存在数据库中，避免标记长期积累。
- 单份草稿最大 12MB，每账号最多 200 份云端草稿；超限保留本机原稿并拒绝继续保存，不自动删除历史。
- 当前是数据库持久化 + 现有应用进程执行，不是完整持久化任务队列；并未承诺任意任务重启后自动续跑，也未验证 2000 并发。

## 验证方式

1. `backend/src/utils/workspacePersistence.test.ts`：关闭/重新打开临时数据库，验证草稿与任务、账号隔离、版本冲突、远端编号、终态不可反转、GET-only 恢复，以及扫码窗口的过期、数量、幂等与隔离。
2. `backend/scripts/test-workspace-postgres.ts`：真实 PostgreSQL 内创建隔离 schema，验证生产 SQL 方言和事务；测试结束整体回滚，不向上游发起模型调用。
3. `frontend/scripts/test-viral-replicate.mjs`：独立浏览器、所有 API 均为模拟响应、其它外部流量阻断；覆盖费用确认、失败重试、刷新只查询、第二个空缓存浏览器恢复、剪辑 MP4 导出和手机传图。

本轮已通过：后端持久化/资源安全 19 项测试、前端复刻工作流 12 项测试，以及真实 PostgreSQL 回滚集成测试。前后端类型检查通过；本地 10588 后端已重启，健康与就绪检查均为 200，代理/团队模块初始化正常。

浏览器回归已验证：费用确认与失败后的明确重试、刷新不重提任务、空缓存第二设备恢复三个成片与剪辑时间线、手机上传一张商品图并在电脑选用、切换账号不显示上一账号草稿、本地导出可解码的竖屏 MP4。其中图片/视频生成响应全部模拟，实际外部收费请求为 0。尚未做正式域名手机实扫与真实模型出片测试。

## 生产发布前仍需完成

1. 助手会话与导演 3D 工程的服务端保存、冲突处理和旧本机数据迁移界面。
2. 本机剪辑素材上传后引用替换，独立剪辑的云端草稿列表；当前仅云端媒体时间线能够完整跨设备恢复。
3. 后端任务队列/租约/幂等提交：尤其“上游已接受、远端编号尚未落库”的极短窗口，目前只能标待核实，不能靠自动重试解决。
4. 将单机文件画布与媒体逐步迁到共享存储/对象存储，补媒体生命周期、访问权限和备份恢复演练；服务器更换与用户换电脑不是同一件事。
5. 正式域名手机实扫、常见手机浏览器测试、真实用户数据规模的压测和生产构建/发布验证。本轮无真实付费模型测试。
6. 剪辑工作台的手机布局仍需专门适配；当前建议电脑剪辑，手机用于扫码传图。本轮手机传图页面验证通过，不等于全站手机创作体验已达上线标准。

部署至少保留：同库 PostgreSQL、`data/oss`、`data/canvases` 及既有 `data/media`；Docker 的 `xoi-data` 数据卷要保留。数据库备份不能代替媒体备份，浏览器缓存也不能代替二者。
