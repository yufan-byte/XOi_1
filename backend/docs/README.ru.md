## 🌟 Основные возможности

- ✅ **Бесконечный холст для производства** — организация сценариев, персонажей, раскадровок, ресурсов и видеоузлов на бесконечном холсте со свободной компоновкой и параллельным производством.
- ✅ **Трехуровневая система агентов** — уровни принятия решений, исполнения и контроля охватывают декомпозицию задач, генерацию контента, контроль качества и ревизию.
- ✅ **Постоянная память агентов** — межсессионная система памяти на основе локального векторного поиска ONNX (краткосрочные сообщения, долгосрочные сводки, семантический поиск).
- ✅ **Программируемая система провайдеров** — пишите TypeScript-логику провайдеров прямо в центре настроек с мгновенным применением без перезапуска.
- ✅ **Адаптация на основе графа событий глав** — автоматическое извлечение и структурирование событий глав исходного романа для точной адаптации.
- ✅ **Файловая конфигурация Skill** — ключевые промпты ScriptAgent и ProductionAgent вынесены в Markdown-файлы Skill для онлайн-редактирования.

## 🚀 Быстрый старт

1. Запустите сервис и войдите (по умолчанию: `admin` / `admin123`).
2. Настройте модели провайдеров (текст / изображение / видео) в центре настроек.
3. Создайте проект, импортируйте исходный роман и извлеките события глав.
4. Используйте ScriptAgent для генерации каркаса истории, стратегии адаптации и структурированного сценария.
5. Переключитесь на ProductionAgent и организуйте раскадровки, ресурсы и видеоузлы на бесконечном холсте.
6. Доработайте изображения раскадровок и соберите итоговое видео.

> ⚠️ **Первый вход** — аккаунт: `admin`, пароль: `admin123`. В продакшене измените пароль через переменную окружения `XOI_ADMIN_PASSWORD`.

## 🚀 Установка

### Требования

- ✅ Эндпоинт LLM API
- ✅ Эндпоинт генерации видео
- ✅ Эндпоинт генерации изображений

### Локальный запуск

```bash
yarn install
yarn dev        # режим разработки, порт 10588
yarn build      # сборка для продакшена
yarn start      # запуск продакшен-сборки
```

### Docker

```shell
docker build -t xoi .
docker run -d -p <локальный-порт>:10588 -v <путь-к-данным>:/app/data xoi
```

### Переменные окружения

| Переменная            | Описание                                          |
| --------------------- | ------------------------------------------------- |
| `NODE_ENV`            | Среда выполнения, `prod` — продакшен             |
| `PORT`                | Порт сервиса (по умолчанию 10588)                 |
| `OSSURL`              | URL доступа к статическим ресурсам                |
| `XOI_ADMIN_USERNAME`  | Имя администратора (только при первой инициализации, admin) |
| `XOI_ADMIN_PASSWORD`  | Пароль администратора (только при первой инициализации, admin123) |

### Развертывание на облачном сервере

```bash
# 1. Установите Node.js / Yarn / PM2
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.7/install.sh | bash
source ~/.bashrc
nvm install 24
npm install -g yarn pm2

# 2. Развертывание
cd /opt
git clone <ваш-репозиторий-xoi>
cd <repo>
yarn install
yarn build

# 3. Настройка PM2 (pm2.json)
```

```json
{
  "name": "xoi",
  "script": "data/serve/app.js",
  "instances": "max",
  "exec_mode": "cluster",
  "env": { "NODE_ENV": "prod", "PORT": 10588, "OSSURL": "http://127.0.0.1:10588/" }
}
```

```bash
# 4. Запуск сервиса
pm2 start pm2.json
pm2 startup
pm2 save
```
