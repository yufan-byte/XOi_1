## 🌟 ฟีเจอร์หลัก

- ✅ **เวิร์กเบนช์แคนวาสไม่จำกัด** — จัดระเบียบบท ตัวละคร สตอรีบอร์ด ทรัพยากร และโหนดวิดีโอบนแคนวาสไม่จำกัด พร้อมการจัดวางอิสระและการผลิตแบบขนาน
- ✅ **ระบบ Agent สามชั้น** — ชั้นตัดสินใจ ชั้นปฏิบัติการ และชั้นกำกับดูแล ครอบคลุมการแตกงาน สร้างเนื้อหา ตรวจคุณภาพ และรีวิวแก้ไข
- ✅ **หน่วยความจำ Agent แบบถาวร** — ระบบหน่วยความจำข้ามเซสชันบนการค้นหาเวกเตอร์ ONNX ในเครื่อง รองรับข้อความระยะสั้น สรุประยะยาว และการค้นคืนความหมาย
- ✅ **ระบบ Vendor แบบเขียนโค้ดได้** — เขียนลอจิก TypeScript ของ vendor ได้ในศูนย์ตั้งค่าและนำไปใช้ทันทีโดยไม่ต้องรีสตาร์ท
- ✅ **การดัดแปลงด้วยกราฟเหตุการณ์บท** — ดึงและจัดโครงสร้างเหตุการณ์ของแต่ละบทจากนวนิยายต้นฉบับอัตโนมัติเพื่อการดัดแปลงที่แม่นยำ
- ✅ **การตั้งค่า Skill เป็นไฟล์** — พรอมพ์หลักของ ScriptAgent และ ProductionAgent แยกออกเป็นไฟล์ Markdown Skill สำหรับการแก้ไขออนไลน์

## 🚀 เริ่มต้นใช้งาน

1. เริ่มบริการและเข้าสู่ระบบ (ค่าเริ่มต้น: `admin` / `admin123`)
2. ตั้งค่า vendor โมเดล (ข้อความ / รูปภาพ / วิดีโอ) ในศูนย์ตั้งค่า
3. สร้างโปรเจกต์ นำเข้านวนิยายต้นฉบับ และแยกเหตุการณ์ของบท
4. ใช้ ScriptAgent สร้างโครงเรื่อง กลยุทธ์การดัดแปลง และบทที่มีโครงสร้าง
5. สลับไปที่ ProductionAgent จัดระเบียบสตอรีบอร์ด ทรัพยากร และโหนดวิดีโอบนแคนวาสไม่จำกัด
6. ปรับแต่งภาพสตอรีบอร์ดแล้วประกอบวิดีโอสุดท้าย

> ⚠️ **เข้าสู่ระบบครั้งแรก** — บัญชี: `admin` รหัสผ่าน: `admin123` ในโปรดักชัน ให้เปลี่ยนรหัสผ่านผ่านตัวแปรสภาพแวดล้อม `XOI_ADMIN_PASSWORD`

## 🚀 การติดตั้ง

### ข้อกำหนดเบื้องต้น

- ✅ เอนด์พอยต์ LLM API
- ✅ เอนด์พอยต์สร้างวิดีโอ
- ✅ เอนด์พอยต์สร้างรูปภาพ

### รันในเครื่อง

```bash
yarn install
yarn dev        # โหมดพัฒนา พอร์ต 10588
yarn build      # บิลด์โปรดักชัน
yarn start      # รันโปรดักชัน
```

### Docker

```shell
docker build -t xoi .
docker run -d -p <พอร์ตท้องถิ่น>:10588 -v <เส้นทางข้อมูล>:/app/data xoi
```

### ตัวแปรสภาพแวดล้อม

| ตัวแปร                 | คำอธิบาย                                             |
| ---------------------- | ---------------------------------------------------- |
| `NODE_ENV`             | สภาพแวดล้อมรันไทม์ `prod` คือโปรดักชัน              |
| `PORT`                 | พอร์ตบริการ (ค่าเริ่มต้น 10588)                       |
| `OSSURL`               | URL เข้าถึงทรัพยากรแบบคงที่                          |
| `XOI_ADMIN_USERNAME`   | ชื่อผู้ดูแลระบบ (เฉพาะการเริ่มต้นครั้งแรก, admin)     |
| `XOI_ADMIN_PASSWORD`   | รหัสผ่านผู้ดูแลระบบ (เฉพาะการเริ่มต้นครั้งแรก, admin123) |

### ติดตั้งบนเซิร์ฟเวอร์คลาวด์

```bash
# 1. ติดตั้ง Node.js / Yarn / PM2
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.7/install.sh | bash
source ~/.bashrc
nvm install 24
npm install -g yarn pm2

# 2. ติดตั้งโปรเจกต์
cd /opt
git clone <ที่อยู่ repo XOi ของคุณ>
cd <repo>
yarn install
yarn build

# 3. ตั้งค่า PM2 (pm2.json)
```

```json
{
  "name": "xoi",
  "script": "data/serve/app.js",
  "instances": "max",
  "exec_mode": "cluster",
  "env": { "NODE_ENV": "prod", "PORT": 10588, "OSSURL": "http://127.0.0.1:10588/" }
}
```

```bash
# 4. เริ่มบริการ
pm2 start pm2.json
pm2 startup
pm2 save
```
