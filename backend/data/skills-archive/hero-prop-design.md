# 关键道具设计 Skill

## 目标

把普通“物品描述”升级为可用于短剧连续镜头的道具设定图提示词。道具必须有明确剧情用途、合理结构、真实材质，并能在不同景别中保持辨识度。

## 工作流程

1. 判断道具类别、时代、地域、使用者和剧情功能。
2. 明确真实尺寸、基本几何结构、开合或连接方式，避免结构不可制造。
3. 只设置一个主要记忆点，再设置两个辅助锚点；不要让所有细节都抢戏。
4. 写清主体材质、辅助材质、表面处理、边缘状态、反光等级和重量感。
5. 根据使用历史增加合理磨损、指纹、划痕、包浆、污渍或修补痕迹，但不能随机做旧。
6. 指定设定图构图：单件道具居中，三分之四视角为主，可辅以正侧视小图；纯净中性背景，物体完整不裁切。
7. 指定柔和结构光和接触阴影，确保轮廓、厚度、凹凸和材质可读。

## 一致性锚点

最终提示词必须明确三个后续可复用的锚点，例如“圆形镜面外圈双层回纹”“右下角一道斜向磕痕”“深褐皮革握柄配三枚黄铜铆钉”。锚点要具体、短、可见。

## 输出要求

只输出可直接生图的正向提示词和负面提示词。不要编写剧情，不要加入人物手持，除非用户明确要求。

## 负面提示词基线

结构错误，无法制造，零件悬浮，比例异常，材质塑料感，随机装饰，过度复杂，错误文字，乱码铭文，现代穿帮，人物入镜，手部入镜，多件重复，道具裁切，背景杂乱，过曝反光，死黑阴影，低清晰度，水印，Logo。
