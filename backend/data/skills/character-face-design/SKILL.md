# 原创AI角色捏脸（定妆照提示词方法论）

## 核心原则（必须遵守）

- 不参考真实人物照片；不生成明星脸、网红脸、影视角色相似脸；用户要求"像某个明星"时拒绝相似脸，改为原创气质方向。
- 先设计面部结构（脸型→三庭五眼→五官主次），不堆砌"好看、精致、高级"等空泛词——把气质拆成可控制的视觉特征。
- 一张脸只有一个主要记忆点，其余五官做辅助："一个强项，两个辅助"。
- 角色脸部设计必须服务人物气质；最终提示词必须完整、可直接复制生图。

## 用户输入信息

年龄感、性别、角色气质（成熟清冷/亲和少女/英气/温柔/疏离/明亮/古典/理性等）、角色身份（女主/反派/古风嫡女/品牌虚拟人等）、画面类型（胸像特写/半身/全身定妆照）、背景（灰底影棚/白底/纯色/电影感）、风格、特殊要求（不微笑/伦勃朗阴影/低饱和妆面等）。缺失时按气质自动补全，但不能补成明星脸。

## 工作流程（九步，按序执行）

1. **理解角色设定**：分析年龄感、性格、距离感、亲和度、成熟度、攻击性、视觉记忆点。成熟清冷型→轻微长中庭、干净骨相、眼神克制、五官收敛、低饱和妆面、明亮有结构的影棚光；亲和少女型→短中庭、略宽眼距、柔和面中、清透妆面、自然表情。
2. **设计脸型结构**：输出脸型类型、外轮廓、下颌线、颧骨存在感、面颊饱满度、下巴比例、骨相气质。圆脸→亲和年轻；短圆鹅蛋脸→少女甜感；偏窄鹅蛋脸→清冷成熟；长脸→成熟距离感；方脸→理性稳重；高颧骨加冷感但不过度；下巴过尖易网红化必须避免。写成可直接进提示词的描述。
3. **设计三庭五眼比例（最重要）**：输出中庭、下庭、眼距、眉眼间距、鼻梁、下巴、面中饱满度，且必须与气质绑定。中庭偏长→成熟冷静疏离；中庭偏短→年轻亲和少女感；眼距略宽→松弛无辜柔和；眼距略窄→集中锐利清冷；眉眼距近→压迫攻击性；眉眼距自然→舒服亲和；下庭偏短→年轻感；下庭自然或略长→成熟感；鼻梁过高易网红化避免。
4. **设计五官主次**："一个强项，两个辅助"，输出主要记忆点五官+辅助一+辅助二+协调关系。禁止全部强项。规避冲突：狐狸眼+钩鼻+尖下巴=反派巫婆感；大圆眼+超薄唇=幼态与成熟冲突；娃娃脸+强下颌=年龄感混乱；短中庭+过高鼻梁=网红脸；全突出=攻击性过强。
5. **设计表情与眼神**：服务气质不乱写微笑。成熟清冷→自然放松无明显笑意眼神沉稳；亲和少女→自然表情眼神明亮真诚不需要微笑；英气→眼神坚定嘴角平直；温柔→面部放松眼神柔和；反派→写眼神压迫感眉眼收紧面部克制（不写邪魅）。用户要求不微笑时正向与负面同写。
6. **设计妆造记忆点**：发型发色发丝、妆面底妆眉形唇色、服装领口面料配饰色彩。妆造不改变脸型比例、服务气质、不要廉价影楼风、不要网红妆、服装不抢面部重点。
7. **设计画面形式**：胸像特写→只拍头部肩颈锁骨到胸口上方、面部占主要面积、禁止全身/七分身/半身过远；灰底影棚→背景干净无杂物、高级商业摄影、人物与背景轻微分离；定妆照→影视角色前期定妆照属性、表情自然姿态克制、不要强剧情动作。
8. **设计光线**：清冷角色→明亮影棚光+轻微伦勃朗阴影；亲和角色→柔和均匀主光+弱阴影；成熟角色→保留面部结构阴影；少女→阴影不过重；定妆照不做过度电影暗光。"明亮+伦勃朗"要写清：曝光明亮通透不暗调不压黑、主光左前上方、右侧脸颊轻微三角阴影、阴影浅净分层展现鼻梁颧骨面中下颌、弱补光留暗部。
9. **生成完整生图提示词**：按 references/templates.md 模板组装（含条件化负面词追加规则）；需要成品基线参考时读 references/examples.md。

## 输出格式

1. 角色分析：一句话说明脸型、比例、五官主次和气质方向。
2. 完整AI提示词：代码框。
3. 负面提示词：代码框（通用+按画面类型/表情/光线条件追加）。
用户只要提示词时只输出提示词与负面提示词，不做额外解释。

## 输出格式硬性要求

**画布内执行路径（必须优先）**：调用 generate_image 时传 faceSpec 表单（subject、age、vibe、framing、faceShape、proportions、memoryFeature、assistFeatures、expression、hairMakeup、wardrobe，可选 lighting/background/extraNotes/noSmile/youthful），系统会自动装配完整九段提示词并展示给用户——不要自己手写长文，也不要压缩成短段落。九步设计方法论用于**填好这张表单的每个字段**。

**纯文本交付路径（用户只要提示词、或在画布外使用时）**：人物提示词必须是分段结构化长文（总字数不少于400字），按九段组织：画面类型与构图→角色设定→脸型结构→三庭五眼比例→五官主次→表情眼神→妆造服装→光线→画面要求与负面约束。禁止压缩成一段短描述、禁止合并段落、禁止省略负面约束。

## 输出范例（换角色时替换设定与五官描述，格式与段落数保持不变）

生成一张原创中国古典女性角色半身定妆照，中性灰色影棚背景，高级商业摄影质感，真人写实风格，构图为半身胸像，只拍摄头部到腰部以上，画面重点集中在面部比例、五官结构和古典气质表达，人物面部占画面主要面积，肩颈自然入镜。
角色设定为22岁左右的原创中国古典女性角色，气质娇媚、伶俐、眼波含情，聪明机敏，有风情但不轻浮。不参考任何真实人物、明星、网红或影视角色。
脸型为古典鹅蛋脸，脸部轮廓柔和流畅，颧骨平缓，下颌线柔和清晰，下巴圆润微收，整体骨相温润秀气。
面部比例为中庭适中偏短，眉眼距离自然，眼距略宽，鼻梁线条柔和秀气但不过度高挺，下庭偏短，面颊自然饱满，整体呈现年轻、娇俏、含情的古典气质。
五官组合遵循一个强项两个辅助的逻辑。主要记忆点是眼睛，杏眼含情，眼型偏圆偏长，眼尾轻微上扬带勾，眼神明亮流转、含情带笑意；眉毛为辅助项，纤细柳叶眉，眉形弯而柔和；嘴巴为辅助项，樱桃小嘴，唇形饱满，唇色为古典胭脂红，嘴角轻微上扬，似笑非笑，不露齿。
表情为娇俏自然，眼神含情，似笑非笑，不露齿，不要夸张表情。
发型为古典盘发发髻，乌黑发丝光洁盘起，鬓边留有柔和碎发，佩戴素雅发饰；妆容为清透妆面，底妆干净保留真实皮肤纹理；服装为古典交领襦裙，颜色低饱和，面料真实有细腻织物质感，整体造型服务角色气质。
光线为明亮柔和的影棚主光从左前方偏上方照射，整体曝光干净通透，右侧脸颊保留一层轻微伦勃朗三角阴影，阴影浅、干净、有层次，弱补光保留暗部细节。背景为中性灰影棚背景，干净无杂物。
画面要求：真实皮肤纹理，毛孔自然，发丝清晰，五官自然协调，面部结构稳定，高级摄影，原创角色，有辨识度。负面约束：明星脸，网红脸，撞脸，锥子脸，蛇精脸，过度磨皮，塑料皮肤，AI假脸，五官过度精修，鼻梁过高，下巴过尖，妆容廉价，影楼风，二次元，卡通，低清晰度，脸部变形，表情夸张，露齿大笑，多人同框，背景杂乱。

## 关键速查

- 比例→气质：中庭长=成熟疏离；中庭短=年轻亲和；眼距宽=松弛无辜；眼距窄=锐利清冷。
- 通用负面词：明星脸、网红脸、撞脸、真实/影视角色相似脸、过度磨皮、塑料皮肤、油腻高光、AI假脸、五官过度精修、锥子脸、蛇精脸、眼睛过大、鼻子过尖、嘴唇过厚、妆容廉价、影楼风、二次元、卡通、低清晰度、脸部变形、表情夸张、多人同框、背景杂乱。
- 用户上传参考图：只分析结构/比例/妆造/气质，不生成相似脸。
