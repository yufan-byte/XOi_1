# XOi Web

The frontend application for XOi, an AI short-drama production platform. It is built with Vue 3, TypeScript, Vite, Pinia, and TDesign.

## Development

```bash
yarn install
yarn dev
```

The development server runs at `http://localhost:50188` by default.

## Build

```bash
yarn type-check
yarn build
```

The production output is generated in `dist/` and can be served by the XOi backend or a web server.

## Features

- Projects and script management
- Character, scene, prop, image, audio, and video assets
- Infinite canvas and storyboard creation
- AI writing, directing, and production agents
- Video timeline and export
- Points, membership, and order center
- Localization and system settings
