# XOi Web

XOi AI 短剧创作平台的前端应用，基于 Vue 3、TypeScript、Vite、Pinia 和 TDesign 构建。

## 开发

```bash
yarn install
yarn dev
```

默认开发地址：`http://localhost:50188`。

## 构建

```bash
yarn type-check
yarn build
```

生产构建产物位于 `dist/`，由后端服务或 Web 服务器托管。

## 主要模块

- 项目与剧本管理
- 角色、场景、道具和音视频资产管理
- 无限画布与分镜创作
- AI 编剧、导演和生产 Agent
- 视频时间线与导出
- 积分、会员和订单中心
- 多语言与系统设置
